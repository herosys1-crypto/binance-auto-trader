# C05. 대칭성 (Symmetry!)

## 원칙
UI ↔ Backend = 100% 동일!
- 옵션 값 = 동일 리스트!
- 검증 로직 = 동일!
- 표시 = 동일!

## 사장님 사고
- UI에서 = 신 옵션 추가!
- Backend에서도 = 반드시 지원!
- 안 그러면 = 사장님 = "옵션 오류" 답답!

## 예시 (v131 사고!)
- HTML dropdown = 강제 SL 0~100 (16개!)
- Backend = 0~100 지원!
- **JS 검증 = 4개만!** ← drift!
- = "on:30" 오류 = 사장님 답답!

## 에이전트 적용

- Audit Team = 대칭성 자동 검증!
