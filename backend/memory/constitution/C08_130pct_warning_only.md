# C08. 130% 자본 = 경고만!

## 원칙
사장님 자본 대비 총 세팅 = 130% 초과 시 = 경고만!
사장님 = 세팅 그대로 진행 가능!

## 사장님 사고
- 사장님 자율 = 100% 존중!
- 시스템 = 차단 X = 경고만!
- 사장님 = 위험 감수 = 자율!

## 계산
```
자본 한도 = 초기 자본 × 1.3
= 여유 자금 30% 확보!

if 총 세팅 > 자본 한도:
    → 경고 알람 (진행 허용!)
```

## 예시
- 초기 자본 1000 USDT
- 130% 한도 = 1300 USDT
- 사장님 세팅 총 1500 USDT
- → 경고 알람 표시!
- → 사장님 = "진행!" 선택 가능!

## 진입 시
- 세팅값 그대로! (자동 차감 X!)
- 사장님 사상 = 예측 가능!
