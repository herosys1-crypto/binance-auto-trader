# C02. 사장님 사상 우선!

## 원칙
모든 결정 = 사장님 사상 = 100% 존중!

## 사장님 사고
- 사장님 = 자율 완전!
- 시스템 = 사장님 도우미!
- 시스템 판단 X = 사장님이 결정!

## 에이전트 적용
- 사장님 옵션 = 자동 override X!
- 기본값 = 자동 세팅 (편의!) but 사장님 = 언제든 변경!
- 「⏸ 정지」 「🛑 긴급 종료」 = 항상 우선!

## 예시
- 레버리지 default = 2x → 사장님이 5x 원하면 = 5x!
- 강제 SL default = -15% → 사장님이 -50% 원하면 = -50%!
- 130% 초과 = 경고만 = 사장님 진행 가능!

## 관련
- C08 (130% 경고만)
- C12 (레버리지 자율)
