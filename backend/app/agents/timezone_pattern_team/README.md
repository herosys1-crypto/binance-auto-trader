# 🌏 Timezone Pattern Team

한국 시간 급등락 통계 → 심볼별 시간대 패턴 → 사장님 매매 정밀도 극대!

## 사장님 사고
「미국 외 지역 (아시아/유럽!) = 가격 조작 의심!」
「한국 시간 = 급등락 시간대 통계 필요!」
「예: BTCUSDT = 새벽 03시 KST = 45% 급등 빈번!」

## 5개 에이전트

### 1. `kst_pivot_recorder` (매일 06:00 UTC!)
- 24h 모든 급등/급락 시점 기록!
- UTC → KST 변환 (+9h!)
- DB `timezone_pivots` 저장!

### 2. `timezone_stats_calculator` (매주 1회!)
- 각 심볼 = 최근 30일 통계!
- 시간대 (0~23) x 요일 (0~6)
- 급등 % / 급락 %
- DB `timezone_stats` 갱신!

### 3. `symbol_pattern_analyzer`
- 심볼 특성 분류:
  - 미국 시간 강함 (0~6 KST!)
  - 아시아 강함 (9~18 KST!)
  - 유럽 강함 (18~24 KST!)

### 4. `heatmap_generator`
- 대시보드 시각화!
- 24시간 x 요일 heatmap!
- 색상 = 급등 빈도!

### 5. `regional_alert_agent` (매 30분!)
- 상위 통계 시간대 = 도래!
- 예: "BTCUSDT = 20분 후 = 45% 급등 시간대!"
- Telegram 알림!
