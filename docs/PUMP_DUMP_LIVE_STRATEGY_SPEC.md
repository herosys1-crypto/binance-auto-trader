# ⚡ 5분·15분봉 급등락 실시간 진입 전략 spec (v141)

**작성일**: 2026-08-14
**요청자**: 사장님 — *"5분봉과 15분봉에서 20% 정도의 급등락을 급등락 실시간 진입 전략으로 해줘"*
**근거 데이터**: 181심볼 × 5m 7,200봉(25일) + 15m 2,400봉 — 실측
**구현 상태**: ✅ 분석/학습 100% (읽기 전용) — ❌ 자동 주문 X

## 🎯 핵심 질문은 「방향」이었습니다

기존 v133c는 **「5분 +3% = 즉시 LONG 추격 / −3% = 즉시 SHORT 추격」** 입니다.
20%대 급등락에서도 같은 방향이 맞을까요? → **과거 캔들에서 직접 셌습니다.**

### 측정 방법

1. 롤링 창(5m: 30분/1시간/2시간, 15m: 1/2/4시간)에서 누적 변동이 임계%를 **처음 넘는 순간** = 이벤트
   (같은 급등을 중복 계산하지 않도록 창 길이만큼 쿨다운)
2. 이벤트 시점 종가로 진입했다고 보고, 이후 **4시간 동안 TP와 SL 중 무엇이 먼저 닿는지** 판정
   - 한 봉에서 둘 다 닿으면 **SL 우선** (보수적 = 실제보다 나쁘게)
3. 기대값 = TP확률 × TP% − SL확률 × SL% (미결은 0)

> MFE/MAE(최대 유리·불리 움직임)만으로는 **순서**를 알 수 없어 손익을 판단할 수 없습니다.
> 그래서 「선착 판정」을 핵심 지표로 삼았습니다.

## 📊 결론 2 — 작은 TP는 독입니다

| TP/SL | 5m 20% 1시간 급등 (추격 LONG) |
|---|---|
| +3%/−3% | TP선착 49.7% / SL 50.3% → **−0.02%** |
| +5%/−3% | 39.5% / 60.5% → +0.16% |
| **+10%/−5%** | 35.1% / 63.8% → **+0.32%** |

승률은 오히려 **떨어지는데 기대값은 올라갑니다.**
변동성이 워낙 커서 작은 TP는 도달 전에 SL을 먼저 맞기 때문입니다.
→ **큰 TP + 짧은 SL(비대칭 손익비)만 살아남습니다.**

## 🌟 v147d — 사장님 결정: 상한 22.5% → **27.5%** 확대

> 사장님 (2026-08-14): *"27.5로 해줘"*

### 그런데 그냥 넓히면 **오히려 나빠집니다**

상한만 바꾸고 플레이북 하나로 쓰면 어떻게 되는지 먼저 재측정했습니다
(`study_15m_pump_bands.py --bands 17.5:22.5,22.5:27.5,17.5:27.5`):

| 창 | 17.5~22.5% (분리) | 22.5~27.5% (분리) | **17.5~27.5% 통합** |
|---|---|---|---|
| 1시간 | +0.18% (+5/−5) | **+1.59%** (+15/−7) | +0.23% (+10/−5) |
| 2시간 | +0.00% = 신호 X | +0.14% (표본잡음) | **−0.07%** ❌ |
| 4시간 | +0.23% (+5/−5) | −0.10% ❌ | +0.16% |

**하위 밴드마다 최적 TP/SL 이 다르기 때문**입니다 — 20% 전후는 `+5%`가 맞고
22.5% 이상은 `+15%`가 맞는데, 하나로 묶으면 절충값(+10%)이 되어 양쪽 모두에 안 맞습니다.
그래서 **밴드는 27.5%까지 넓히되, 하위 밴드는 분리해서** 각자의 플레이북을 씁니다.

### 22.5~27.5% 는 과최적화가 아닌가? — TP/SL 전 조합 검증

「16개 조합 중 최댓값 하나」를 고르면 부풀려지므로, 9개 TP/SL × 양방향을 전부 봤습니다.

| TP/SL | LONG 기대값 | SHORT 기대값 |
|---|---|---|
| +3/−3 | −1.11% | −0.53% |
| +5/−5 | −0.22% | −0.66% |
| +7/−5 | **+0.20%** | −0.87% |
| +10/−7 | **+1.12%** | −1.25% |
| **+15/−7** | **+1.59%** | −1.85% |
| +15/−10 | **+1.67%** | −2.63% |
| +20/−10 | **+0.79%** | −3.68% |

- **LONG 9개 중 6개 양수 / SHORT 0개 양수** → 방향은 확실히 LONG
- TP 를 키울수록 좋아지다가 +20% 에서 꺾이는 **일관된 형태** = 우측 꼬리형
  (급등이 계속 달리는 구간이라 작은 TP 는 노이즈에 먼저 잘림)
- 즉 한 칸만 좋은 게 아니라 **구조가 있는 결과** → 채택

반면 **2시간 창은 LONG 1/9·SHORT 2/9** 만 양수 = 노이즈,
**4시간 창은 양방향 0/9** = 신호 없음 → 둘 다 진입하지 않습니다.
(밴드별 최적 1개만 봤을 때는 2시간이 SHORT +0.14%로 보였는데,
 전 조합을 보니 근거가 없었습니다 — 최댓값만 보면 안 되는 사례입니다.)

### ⚠️ 이 밴드의 성격 = 「자주 지고 가끔 크게 이긴다」

TP 선착 **36%**. 나머지 **64% 는 −7% 손절/시간초과**입니다.
기대값이 +인 이유는 이기는 판이 +15% 로 크기 때문이며,
**연패를 견딜 수 있는 자본에서만** 의미가 있습니다.
화면에도 이 경고를 항상 함께 띄웁니다.

또한 표본이 **114건 / 25일치**뿐입니다. 꼬리에 의존하는 전략은
표본이 적을수록 추정이 불안하므로, 5m·15m 장기 재수집 후 재검증이 필요합니다.

### v147d 최종 규칙

```
15m: 17.5% ≤ |변동| < 27.5%  → 신호 대상 (그 밖은 신호 없음!)

  ├ 17.5~22.5% (20% 전후 = 짧게)
  │   · 1시간 창 → 추격 LONG  +5%/−5%   (EV +0.18%, 255건, TP선착 51.4%)
  │   · 2시간 창 → 신호 없음             (EV  0.00%, 416건)
  │   · 4시간 창 → 추격 LONG  +5%/−5%   (EV +0.23%, 546건, TP선착 49.1%)
  │
  └ 22.5~27.5% (v147d 신설 = 길게)
      · 1시간 창 → 추격 LONG  +15%/−7%  (EV +1.59%, 114건, TP선착 36.0%) ⚠️꼬리형
      · 2시간 창 → 신호 없음             (LONG 1/9·SHORT 2/9 = 노이즈)
      · 4시간 창 → 신호 없음             (양방향 0/9)

  급락 → 전 구간 진입 비권장 (v141 결론 유지)
5m  → 신호 없음 (v141b 사장님 결정 = 측정만!)
```

밴드 밖이면 **왜 신호가 없는지** 화면에 명시합니다
(예: `15m 변동 +30.0% 는 밴드(17.5~27.5%) 밖 = 신호를 내지 않습니다`).

## 🎯 v141b — 최종 결정: **15분봉 20% 전후만** 사용

> 사장님: *"급등락 실시간 진입은 15분봉 20%전후 급등락으로 해주고"*

**5분봉 신호를 껐습니다** (`ENABLE_5M_SIGNAL = False`).

| 입력 | 결과 |
|---|---|
| 5m +30% | ➖ 신호 없음 |
| **15m +20%** | **🚀 B등급 추격 LONG (+5%/−5%)** |

(v147d 로 상한만 넓혔고, 그 안에서 하위 밴드별 TP/SL 을 씁니다.)

### 감지

```
15m 창: 1시간(4봉) / 2시간(8봉) / 4시간(16봉)   ← 진입 신호는 여기서만!
5m  창: 30분/1시간/2시간                         ← 참고 측정 전용 (신호 X)
→ 각 창의 누적 변동률 계산 (진행 중 봉 포함 = 실시간!)
→ 15m 변동이 17.5~27.5% 밴드 안일 때만 이벤트 (v147d)
```

### 판정

| 조건 | 등급 | 처리 |
|---|---|---|
| **15m** 급등 + 17.5~22.5% + 1시간/4시간 창 | **B** | 추격 LONG +5%/−5% (짧게) |
| **15m** 급등 + **22.5~27.5%** + **1시간 창** | **B** | 추격 LONG **+15%/−7%** (길게) ⚠️꼬리형 |
| **15m** 급등 + 17.5~22.5% + **2시간 창** | **D** | **신호 없음** (실측 EV 0.00%) |

### 화면에 항상 함께 표시하는 것

- **TP 선착률 + 표본 수** (근거의 크기)
- **기대값(수수료 전)** 과 **기대값(수수료 차감 후)** 를 나란히
- **정점 대비 현재 위치** — 이미 밀렸으면 「급등이 끝난 뒤」일 수 있다는 경고
- **승률이 30~40%대라 연속 손실이 길다**는 경고

## ⚠️ 반드시 알고 쓰셔야 하는 한계

1. **기대값 +0.2~0.76%는 수수료 차감 전입니다.**
   왕복 taker 수수료 약 **0.08%** 를 빼야 합니다.
2. **슬리피지가 큽니다.** 20% 급등 중인 알트는 호가 스프레드가 벌어져
   진입·청산에서 **0.1~0.5% 이상** 더 손실이 날 수 있습니다.
   → **실제 기대값은 0에 가깝거나 마이너스일 수 있습니다.**
   → 가장 여유 있는 건 15m 20% 1시간 급등(+0.76%) 케이스뿐입니다.
3. **승률 30~38%** = 연속 손실이 깁니다. 10연패도 정상 범위입니다.
   자본 관리 없이 쓰면 계좌가 먼저 무너집니다.
4. **표본 기간 25일** = 단일 시장 국면일 수 있습니다.
5. 이벤트 시점은 **완료봉 종가 기준**으로 측정했습니다. 실시간에서는 진행 중 봉을 보므로
   약간의 차이가 있습니다.
6. **자동 주문 X** — 사장님 판단 보조 + 학습 수집 전용입니다.
