# 🔀 20% 급등 후 「지속 상승 vs 하락 전환」 판별 spec (v146)

**작성일**: 2026-08-14
**요청자**: 사장님 —
> *"20% 이상 급등하는 심볼을 1분 5분 차트를 보고 1차 진입을 결정해야 해. 20% 급등 후 지속 상승하는 경우 진입시점을 잡고 최대 3단계 안에서 고점을 잡아야 해."*
> *"롱과 숏을 동시에 생각하고 하는 거. **급등 후 하락할 경우 숏, 지속 상승은 롱 짧게**"*

**데이터**: 181심볼 × 5m 캔들 (25일), 20%+ 급등 **282건**
**재현**: `python scripts/study_pump_continuation.py --cache5m <5m캐시>`

---

## 📌 먼저 알아야 할 세 가지 사실

### ① 20% 급등 후는 **거의 동전던지기**입니다

트리거 후 6시간 내 ±10% 선착 기준:

| 결과 | 비율 |
|---|---|
| 지속 상승 (UP) | **41.1%** |
| 하락 전환 (DOWN) | **48.9%** |
| 미결 | 9.9% |

**오히려 전환이 약간 우세합니다.** 아무 20% 급등이나 들어가면 근거가 없습니다.

### ② 「20% → 100%」는 **0.4%** 입니다

| 트리거 후 도달 | 비율 |
|---|---|
| +30% 이상 | 13.5% (38건) |
| +50% 이상 | 5.0% (14건) |
| **+100% 이상** | **0.4% (1건)** |

> 사장님이 보신 그 심볼은 **282건 중 1건**입니다. 실재하지만 극히 드뭅니다.
> **그 하나를 노리다 나머지 99.6%에서 잃으면 안 됩니다.**

최대 상승 중앙값 **+10.2%** / 최대 하락 중앙값 **−13.0%**.

### ③ 단독 지표로는 **못 가릅니다**

| 특징 | 최대 배수 |
|---|---|
| 거래량 4배+ | 1.18x |
| 가속도 15+ | 1.17x |
| 연속양봉 4~6 | 1.17x |
| 급등 크기 / 직진성 / 속도 | 거의 1.0x |

**전부 무력합니다.** 조합해야 갈라집니다.

## 🎯 판별 로직 (조합)

### 🚀 지속 신호 → **LONG (짧게)**

```
거래량 4배 이상  AND  종가가 봉 상단 70% 이상
```

| 항목 | 실측 |
|---|---|
| 표본 | 57건 |
| **지속** | **52.6%** |
| 전환 | 35.1% |
| +30% 도달 | 19.3% |

기저 41:49 → **53:35** 로 벌어집니다.

### 📉 전환 신호 → **SHORT**

```
가속도 둔화(<0)  AND  거래량 마름(1배 미만)
```

| 항목 | 실측 |
|---|---|
| 표본 | 41건 |
| 지속 | 31.7% |
| **전환** | **48.8%** |

기저 41:49 → **32:49** 로 벌어집니다.

### 👀 중립 → **진입 안 함**

두 조건 모두 미충족 = 41:49 동전던지기 구간입니다.
**이 구간에서 들어가지 않는 것이 이 로직의 절반입니다.**

## 🎛 구현 (`backend/app/services/pump_continuation_analyzer.py`)

### 측정 (전부 현재까지의 데이터만 — 미래 참조 X)

| 특징 | 계산 |
|---|---|
| `move_pct` | 5m 24봉(2시간) 누적 변동률 |
| `vol_ratio` | 최근 6봉(30분) 평균 거래량 / 그 이전 24봉 평균 |
| `accel` | 최근 30분 상승률 − 그 이전 30분 상승률 |
| `streak` | 연속 양봉 수 |
| `close_pos` | 마지막 봉에서 종가의 위치 (0=저가, 1=고가) |
| `straight` | 급등 구간 내 최대 되돌림 (직진성) |

### 진입 계획 (사장님 지시 반영)

| 방향 | TP | SL | 최대 단계 |
|---|---|---|---|
| **LONG (지속)** | **+5%** ← 「짧게」 | −5% | **3단계** |
| SHORT (전환) | +10% | −10% | **3단계** |

> 사장님 지시 「지속 상승은 **롱 짧게**」 → LONG TP를 SHORT의 절반으로 설정했습니다.
> 「최대 3단계 안에서」 → `MAX_STAGES = 3` 하드 설정.

### 화면에 항상 함께 표시

- **기저 41:49** (= 그냥은 동전던지기)
- **+100% 도달 0.4%** (= 큰 건은 극히 드뭄)
- **표본 41~57건** (= 확정된 우위 아님)

## ⚠️ 한계 (그대로 말씀드립니다)

1. **표본 41~57건뿐**입니다. 방향은 잡혔지만 **통계적으로 확정된 우위가 아닙니다.**
2. 5m 캐시가 **25일치**뿐입니다 (4H 연구는 250일). 6개월+ 재수집이 필요합니다.
3. 특징 조합을 여러 개 시험했으므로 **다중검정 편향**이 있을 수 있습니다.
4. 1분봉은 아직 안 썼습니다 — 사장님이 말씀하신 「1분 5분 차트」 중 **5분만** 반영했습니다.
   1분 미시구조(호가 흡수, 순간 거래량)를 넣으면 판별력이 올라갈 수 있습니다.
5. 수수료·슬리피지 미반영. 급등 직후는 스프레드가 넓습니다.
6. **자동 주문 X** — 판단 보조 + 학습 수집 전용입니다.
