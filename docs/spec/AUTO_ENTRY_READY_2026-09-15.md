## 3. 켜는 법 (사장님)

**현재 VPS 에 저장된 값** (9/15 조회):
- `pump_split_capitals = 10,200,500`
- `sajangnim_capital_ladder = 10,300,600`

모두 10/100/200 으로 바꾸려면 아래 두 줄을 적용한다 (**DB 변경 = 사장님 승인 뒤**):
```sql
UPDATE system_settings SET value = '10,100,200' WHERE key = 'pump_split_capitals';
UPDATE system_settings SET value = '10,100,200' WHERE key = 'sajangnim_capital_ladder';
```
`sajangnim_capital_ladder` 는 「10 → 손절 → 300 → 손절 → 600」 **재진입 사다리**다. 분할(동시 보유)과 뜻이 다르다.

**켜는 순서 (예: 기준선보다 나았던 SHORT 3개부터):**
1. 자동매매 재개: `auto_trading_halt = 0`
2. 가족 켜기: `rf_off8_mode = on` · `rf_wick_short_mode = on` · `rf_s2_short_mode = on`
   - 필요하면 `daily_max_rf_off8 = 1` 처럼 가족마다 하루 최대를 정한다.
3. 확인: `python scripts/verify_fix364_deploy.py` 의 「🗓 자동매매 준비」 절
   - 가족별 하루 최대 / 오늘 진입 수
   - 모드·진입 방식
4. 끄기: `<가족>_mode = off` 또는 `auto_trading_halt` 행 삭제 (= 전체 중단). 재시작은 필요 없다.

⚠️ **한 번에 여러 가족을 켜면 노출이 커진다:**
- 가족당 3차까지 차면 310 USDT (레버 2 명목 620)

**남은 위험 (켜기 전에 알 것)**
- **공용 경로:** 하루 최대가 공용 경로(전략 생성 · 1차 주문)에 들어갔다.
  - 프로젝트 규칙 5(가족별 적용)와 다르지만, 사장님 지시가 「모두 일최대 1개」이고 워커가 13개라 한 곳에서 막아야 빠짐이 없다.
  - 재진입류(관리 재진입 · 손절 뒤 재진입 · 익절 뒤 재진입 · 라스트찬스)도 **하루 1건**이 된다. 필요하면 `daily_max_<가족키>` 로 올린다.
- **다른 워커와 겹침:** 생성 커밋부터 1차 주문 커밋까지 수 초 동안 WAITING 행은 다른 워커의 「같은 심볼 활성」 검사에 안 보인다. 다른 워커가 같은 심볼에 들어올 수 있다 (기존 워커 공통 구조).
- **이중 진입:** `rf_confirm_peak` ↔ 급등 정점 SHORT, `rf_bottom_long` ↔ 저점 LONG 은 하루 최대를 공유하지 않는다. 한쪽 손절 직후 다른 쪽이 같은 자리에 들어갈 수 있다 → **한쪽만 켤 것**.
