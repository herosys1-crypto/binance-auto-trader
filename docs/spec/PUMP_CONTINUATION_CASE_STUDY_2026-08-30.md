## 2. 읽어낸 패턴 — 「상승 지속 중 눌림」의 지문

| | 4H RSI(6) | 4H MACD hist | 15m RSI(6) | 15m MACD hist | 15m 밴드 위치 | 판정 |
|---|---|---|---|---|---|---|
| **龙虾** | **96.2** | **양수** | **47.8** | 음수 | **0.519** | 상승 지속 + 단기 눌림 ✅ |
| **PROM** | **92.2** | **양수** | **56.1** | 음수 | 0.695 | 상승 지속 + 단기 눌림 ✅ |
| BTR | 68.1 | 음수 | 87.8 | 양수 | 0.913 | 급락 후 **반등 진행 중** |
| AKE | 40.7 | 음수 | — | 음수 | (1H 0.163) | **조정 심화** ❌ |

### 지문 ①  「4H 과열 + 15분 냉각」 = 눌림목

龙虾·PROM 둘 다 **4H RSI(6) 90 이상**인데 **15m RSI(6) 은 47~56 (중립)** 이다.
같은 종목이 상위 시간대에서는 과열, 하위 시간대에서는 식어 있다.
이것이 사장님이 말씀하신 **"4시간이 조정인데 지속상승하는 심볼"** 의 지표적 모습이다.

    4H RSI(6) ≥ 80   AND   15m RSI(6) ≤ 60      →  눌림목 후보

### 지문 ②  4H MACD 히스토그램의 **부호**가 「지속」과 「이탈」을 가른다

    龙虾 +0.002498 / PROM +0.140    →  상승 지속 (재급등 이어짐)
    BTR  −0.00168  / AKE  −0.0000175 →  추세 꺾임 (조정·하락 국면)

4H RSI 만 보면 BTR(68)이 AKE(41)보다 훨씬 강해 보이지만, **MACD hist 는 둘 다 음수**다.
반대로 龙虾·PROM 은 RSI 도 MACD 도 상승을 가리킨다.
**RSI 는 「얼마나 올랐나」, MACD hist 는 「아직 오르고 있나」를 말한다.** 둘은 다른 질문이다.

### 지문 ③  15m 은 「중단선 지지」에서 멈춘다

    龙虾  종가 0.075249  vs  15m 중단 0.075186   →  중단선 대비 **+0.08%**
    PROM  종가 6.853     vs  15m 중단 6.751     →  **+1.51%**

둘 다 **15분 볼밴 중단선 바로 위**에 붙어 있다. 밴드 위치로는 0.52 / 0.70.
사장님이 "볼밴 중단을 이탈했다가 다시 가는 경우가많아" 라고 하신 그 자리다.

### 지문 ④  CCI 는 15분에서 먼저 음수로 내려간다

    龙虾 4H +94.1 → 15m **−76.8**
    PROM 4H +166.5 → 15m **−33.6**

**상위 시간대는 양수(강세)인데 하위 시간대만 음수**. 조정이 15분에서 먼저 나타난다.
CCI −80 근처는 현행 게이트의 LONG 기준(`CCI_LOW = −80`)과 거의 겹친다.

### 지문 ⑤  OBV 는 4종목 모두 **하락하지 않았다**

AKE 조차 4H OBV 가 1.023T 에서 거의 평평하다 — 가격은 −27% 인데 OBV 는 안 무너졌다.
사장님 원칙 **"obv가 하락하지 않으면 결국은 obv 방향으로 간다"** 에 따르면
AKE 는 「지금 사기엔 이르지만 포기할 자리도 아닌」 상태다.

BTR 은 더 분명하다 — 08/28 에 0.224 → 0.15125 로 **−32% 붕괴**했는데
**4H OBV 는 계속 상승 유지**했고, 실제로 0.196 까지 되돌아왔다.
**가격이 무너져도 OBV 가 안 꺾이면 되돌아온다**는 사장님 말씀의 실물 사례다.

## 3. 판정식 초안 (이 4건에서 도출)

### 3-A. LONG — 「지속 상승 중 눌림」 (龙虾·PROM 형)

```
[4H = 확정된 흐름]
  RSI(6)        >= 80            (과열이지만 추세가 살아 있음)
  MACD hist     >  0             ★ 「아직 오르고 있나」의 답
  OBV           하락 아님         ★ 최종 심판
  밴드 위치      >= 0.8           (상단권. 1 초과 = 상단 밖도 허용)

[15m = 진입 타이밍]
  RSI(6)        <= 60            (충분히 식음)
  MACD hist     <  0             (단기 조정 진행 중)
  밴드 위치      0.4 ~ 0.75       (중단선 부근)
  또는 종가가 15m 중단선 ±1.5% 이내
```

**4건 검증**: 龙흐 통과 / PROM 통과 / BTR 탈락(4H MACD 음수) / AKE 탈락(4H RSI 41).

### 3-B. LONG 금지 — 「원점 회귀」 판별

사장님: *"큰상승후 큰하락해서 원점을 간 심볼은 다시 상승하는 심볼을 찾기는 힘들어"*

```
되돌림 = (고점 − 현재가) ÷ (고점 − 상승 시작가)
```

| | 고점 | 시작가 | 현재 | 되돌림 |
|---|---|---|---|---|
| 龙虾 | 0.078946 | 0.012895 | 0.075225 | **5.6%** |
| PROM | 7.164 | 1.214 | 6.836 | **5.5%** |
| BTR | 0.224 | 0.02840 | 0.19575 | **14.5%** |
| AKE | 0.0163 | 0.0001823 | 0.008103 | **50.6%** |

**되돌림이 작을수록 추세가 살아 있다.** 龙虾·PROM 은 6% 미만, AKE 는 50% 를 넘었다.
사장님이 AKE 를 "정말 어려운 심볼" 이라고 하신 것이 숫자로 나타난다.

    되돌림 <  30%   →  추세 건재. LONG 유리
    되돌림 30~60%  →  판단 보류. OBV 로 가른다
    되돌림 >= 70%  →  원점 회귀. LONG 금지 (단, 학습 대상으로는 계속 관찰)

### 3-C. AKE 형 — 「급등에 급등, 조정도 반복」

AKE 는 08/14 (0.0163) 과 08/29 (0.0123) 두 번의 봉우리를 만들었고 지금 세 번째 조정이다.
현재 4H 밴드 위치 0.448 = **중단선 아래**, 1H 는 0.163 = **하단 근처**.

이 형태는 **단일 규칙으로 잡기 어렵다.** 다만 두 가지는 말할 수 있다:
- 지금 4H RSI 40.7 / MACD hist 음수 → **3-A 의 LONG 조건에 들어오지 않는다** (올바른 배제)
- 4H OBV 가 안 꺾였으므로 **감시는 유지**한다. 되돌림 50.6% 는 「보류」 구간이다.

→ 이런 종목이야말로 **관찰 데이터를 쌓아 사후에 답을 맞춰봐야** 하는 대상이다 (Fix 226).

## 4. 현재 코드와의 격차

| 판정 | 현재 코드 | 격차 |
|---|---|---|
| 4H MACD hist 부호 | `confirm_peak` [C] 블록이 **기록만** 하고 차단 안 함 | **판정에 안 쓰임** |
| 4H RSI 극단 | 진입 게이트에 4H RSI 조건 **없음** (15m 만 봄) | 없음 |
| 15m RSI 냉각 | 게이트는 「RSI ≥ 65 에서 꺾임」만 봄 = **반대 조건** | 눌림목을 못 잡음 |
| 밴드 위치(0~1) | 어디에도 없음. `closes[-1] > bb_up` 같은 bool 뿐 | **연속값 없음** |
| 되돌림 비율 | **없음** | 신설 필요 |
| 15m 중단선 지지 | `bb_mid_last` 는 Fix 131 로 반환되지만 **지지 판정은 없음** | 신설 필요 |
| OBV 하락 여부 | `obv_gate` 가 극단만 차단. Fix 227 로 부호는 바로잡음 | 「하락 아님」의 연속 지표 없음 |

**Fix 226 이 `bb_pos` / `macd_from_peak` / `obv_dir_20` 을 관찰 시점에 기록하기 시작했으므로,
위 판정식의 임계값(80 / 60 / 0.8 / 0.4~0.75 / 30% / 70%)은 며칠 뒤 실측 분포로 교정한다.**
지금 숫자는 **4건에서 뽑은 초안**이며, 그대로 하드코딩하지 않는다.

## 5. 이 문서의 한계

- 표본이 **4건**이고 전부 **사장님이 고르신 성공/난이도 사례**다 = 선택 편향이 있다.
  「같은 조건인데 실패한 종목」이 빠져 있어 임계값의 정밀도를 보장하지 못한다.
- 되돌림 계산의 「상승 시작가」는 차트 왼쪽 끝 값을 썼다. 실제 구현에서는
  **N일 창 안의 최저점** 같은 명시적 정의가 필요하다.
- 4H OBV 가 "하락하지 않았다"는 육안 판정이다. 수치 기준은 Fix 226 의
  `obv_dir_20`(−1~+1) 이 쌓인 뒤 정한다.
