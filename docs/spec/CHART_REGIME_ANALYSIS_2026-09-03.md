## 6. 반증 — 재봤더니 반대였던 것들

### 6-1. 🚨 「지표로 급등/급락 방향을 가른다」는 성립하지 않는다

미래 라벨(사후) + 과거 판정식으로 정식 실험을 했다. 결과:

| 비교 | 최대 \|d\| | 교차검증 통과 지표 |
|---|---|---|
| SURGE **vs** RANGE | 1.35 | 10개 |
| RANGE **vs** BREAKDOWN | 2.16 | 10개 |
| SURGE **vs** BOUNCE | 2.71 | 10개 |
| **SURGE vs CRASH** | **0.41** | **1개** (px_pos96) |
| **BOUNCE vs BREAKDOWN** | **0.48** | 3개 |

**구조축(고변동 상단권 / 수축 보합 / 지지권)은 d=1.3~2.7 로 아주 잘 갈린다.
그런데 그 안에서 방향은 d=0.41 로 거의 안 갈린다.**

더 결정적인 건 **결과 수준의 검증**이다. 방향 판정기를 만들어 표본외로 돌렸더니
예측 SURGE 와 예측 CRASH 의 실제 미래 수익률 차이가:

- A로 적합 → B 검증: **+0.74%p** (SURGE 가 높음, 맞는 방향)
- B로 적합 → A 검증: **−0.43%p** (**CRASH 가 높음, 뒤집힘**)

BOUNCE vs BREAKDOWN 도 −0.26%p / +0.31%p 로 뒤집혔다.

> 🚨 **지표 수준에서 교차검증을 통과해도 결과 수준에서는 뒤집힐 수 있다.**
> 효과크기만 보고 채택하면 안 되고, **예측 국면별 실제 수익률이 갈리는지**까지 봐야 한다.
> 이번에 개별 지표 7~11개가 교차검증을 통과했는데도 최종 분리력은 부호가 뒤집혔다.

### 6-2. 4시간봉을 넣으면 방향이 갈리는가 — 부분적으로만

  4H 계열 최고는 h4_drawdown48 +0.40 인데 **교차검증에서 탈락**(A +0.524 / B +0.095).
- **BOUNCE vs BREAKDOWN**: 최대 \|d\| 0.48 → **0.60**, 교차검증 통과 지표 3 → **11개**.
  1위가 **`h4_body_ratio3` (4시간봉 최근 3봉 몸통 방향) d=+0.596**.

➡️ **지지권에서는 4H 가 방향을 말해준다** (사장님 사상 확인).
   **고변동 상단권에서는 4H 를 넣어도 급등/급락이 안 갈린다** (사상이 여기선 안 통한다).

### 6-3. 🚨 절대 임계값은 종목이 바뀌면 무력해진다 (AKEUSDT 가 증거)

첫 판정식(v1)은 `bb_width ≤ 6.22%`, `atr_pct ≤ 1.74%` 같은 **절대 임계값**으로 보합을 잡았다.
30심볼 뭉친 분포에서는 최고 지표였다 (d=1.06). 그런데 AKEUSDT 현재:

| | 절대값 | 자기 최근 50봉 내 순위 |
|---|---|---|
| 밴드폭 | **13.21%** (전체 분포 p85 = **넓음**) | **0.02** (= 최대 수축) |
| ATR% | 4.20% (넓음) | 0.02 |

**절대값으로는 「확장」, 자기 이력으로는 「최대 수축」 — 정반대다.**
그래서 v1 은 AKEUSDT 의 보합을 **CRASH 85%** 로 오판했다.

같은 함정이 **오실레이터에도** 있었다. AKEUSDT 는 +303% 급등 뒤라
급락 중에도 **RSI24 가 45.3** 에 머문다 (절대 임계 `≤38.97` 에 안 걸림).
그런데 **자기 96봉 내 백분위로는 0.08** — 제대로 「눌린 상태」로 나온다.

➡️ **교훈: 국면 판정에 쓰는 모든 지표는 자기 이력 백분위로 정규화해야 한다.**
   이번 분석에서 이 함정에 **세 번**(밴드폭, ATR, RSI/CCI) 걸렸다.

### 6-4. 내가 만든 버그 2건 (실측이 잡음)

- **교차검증 분할 버그**: 방향 규칙을 적합할 때 훈련집합을 *전역* 홀짝으로 다시 쪼갰는데,
  훈련집합이 이미 한쪽이라 **반대 그룹이 비어 전 지표가 탈락** → 예측 SURGE n=0.
  훈련집합 *안에서* 쪼개도록 고쳤다.
- **잔여 판정 임계 버그**: RANGE 규칙 조건을 in-regime p75 로 잡았더니
  `atr_pct_rank50 ≤ 0.76` 처럼 **전체 봉의 76% 가 충족**하는 조건이 돼
  급락 한복판에서 RANGE 1.00 이 CRASH 0.88 을 이겼다. 중앙값 임계 + 잔여 구조로 고쳤다.

### 6-5. ATR 정규화는 과교정이었다 (v2 폐기)

「절대값이 문제니 ATR 로 나누자」고 `ret12/atr_pct` 로 국면을 정의해봤다.
결과: **급락이 스스로를 지운다.** 급락이 ATR 을 부풀리므로 −23.7% 하락이
ATR 배수로는 −1.5 밖에 안 돼 CRASH 문턱(−1.90)에 못 미쳤다.
AKEUSDT 급락 구간이 **RANGE 79%** 로 나왔다. → 폐기하고 v3(변동성 소멸 우선)로 갔다.

> 🔁 **현재 변동성으로 그 변동성을 만든 움직임을 정규화하면 안 된다.**
