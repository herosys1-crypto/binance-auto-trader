## 1. 정정으로 확정된 두 가지

### ① 손절 −5%/−10% 는 **가격 기준**입니다

사장님 「250」이 그 증거입니다:

```
자본(증거금) 500  × 2x = 명목 1,000  → 가격 5%  역행 = 손실  50
자본        1,000 × 2x = 명목 2,000  → 가격 10% 역행 = 손실 200
                                                     합계 250  ✓
```

ROI 로 환산하면 **−10% / −20%** 입니다.
코드의 `force_sl_roi_override` 는 ROI 기준(`risk_service.py:485` `pnl_ratio = raw_pnl_pct × leverage`)이므로
**override 에 10 / 20 을 넣어야** 사장님 의도와 같습니다.

⚠️ 제가 처음 ROI 기준으로 읽어 125 로 계산했습니다. **사장님 250 이 맞습니다.**
⚠️ 레버리지가 2가 아니면 이 등식이 깨집니다 — 레버리지를 **2로 고정**하거나 손절 %를 레버리지에서 역산해야 합니다.

### ② 주 경로는 「실패 사다리」가 아니라 **「성공 후 추가」**입니다

## 2. 실측 — 사장님 직관이 맞았고, 그것도 크게

급등 사건(24h +30% 돌파) **75건**을 그 시점부터 4일간 걸으며 시뮬레이션했습니다.

### ① 1단계 진입 자리 (정정된 손절 적용)

```
정점 즉시           -3,325.00   건당 -44.33
정점 대비 8%↓          +69.29   건당  +0.92
```

손절이 넓어지자 「정점 즉시」가 **더 나빠졌습니다**(−18.33 → −44.33). 나쁜 자리는 손절을 넓혀도 못 살립니다.

### 🌟 ② 「이겼을 때 추가」가 이 전략의 주 엔진입니다

```
추가 규칙                    합계 USDT      건당
추가 없음                       +69.29     +0.92
가격 2.5%↓ 시 ×0.5 1회       +1,307.11    +17.43
가격 2.5%↓ 시 ×0.5 2회       +2,563.34    +34.18
가격 2.5%↓ 시 ×1.0 1회       +1,643.28    +21.91
가격 2.5%↓ 시 ×1.0 2회       +4,355.73    +58.08   ← 최고
가격 5.0%↓ 시 ×1.0 2회       +2,172.68    +28.97
```

**건당 +0.92 → +58.08 (63배).** 사장님 *"당연히 첫진입부터 성공해서 포지션 추가를 하고 싶은거야"* 가 정확했습니다.

추가 트리거는 **낮을수록 좋습니다**(2.5% > 5.0%) — 빨리 늘리는 쪽이 유리합니다.

### ③ 과적합 검사 — 강하게 통과

```
최근 절반 (37건)  추가없음  +194.3   →  2.5%×1.0 2회  +2,037.2
이전 절반 (38건)  추가없음  -125.0   →  2.5%×1.0 2회  +2,318.5
```

**양쪽 절반 모두 크게 개선.** 한쪽에만 맞은 우연이 아닙니다.

### ④ 승률은 32%입니다 (24승 49패)

이길 때 추가로 크게 버는 **손익비 전략**입니다. 승률로 판단하면 안 됩니다.

## 3. 🚨 핵심 트레이드오프 — 「250」과 수익은 함께 못 가집니다

추가하면 자본이 늘어나므로 **손절 시 손실도 커집니다**:

```
1시도 기본            자본   500  명목 1,000  가격 5%   →  -50
1시도 +2회 추가       자본 1,500  명목 3,000  가격 5%   → -150
2시도 기본            자본 1,000  명목 2,000  가격 10%  → -200
2시도 +2회 추가       자본 3,000  명목 6,000  가격 10%  → -600
```

「추가할 때마다 손절 폭을 줄여 **손실 금액을 고정**」해봤습니다:

| 규칙 | 건당 | **최악 1건** |
|---|---|---|
| ×1.0 추가, 손실 고정 **없음** | **+58.08** | **−650** |
| ×0.5 추가, 손실 고정 없음 | +34.18 | −450 |
| **×0.5 추가, 손실 고정** | **+12.67** | **−250** ✅ |
| ×1.0 추가, 손실 고정 | −2.33 | −250 |

🚨 **손실을 완전히 고정하면(×1.0) 수익이 사라집니다**(+58.08 → −2.33).
손절 폭이 좁아져 노이즈에 잘리기 때문입니다.

**사장님 「250」을 지키면서 흑자인 유일한 조합 = 「추가 자본 절반 + 손실 고정」 (+12.67/건)**

## 4. 설계

### 4.1 모니터링

```
market_movers.rank_map(get_24hr_ticker(), 10) 의 UP 1~10위
  AND quoteVolume >= 5,000,000
  AND Symbol.status == "TRADING"        (신규 — 지금 어떤 워커도 안 본다)
```

`rank_map` 은 **이미 있습니다**(`services/market_movers.py:95-128`). 티커는 Redis 캐시 TTL 30초,
weight 40 → **최대 80/분 = 예산의 5.3%**. API 위험 없습니다.

⚠️ **「당일」 vs 「24h」**: 코드의 모든 랭킹은 **롤링 24시간**입니다. KST 자정 기준은 저장소에 없습니다.

### 4.2 1단계 진입 (필수 — 전부 AND, 다수결 금지)

| # | 조건 | 근거 |
|---|---|---|
| M1 | 급등 1~10위 + 거래대금·상장 필터 | 원문 |
| M2 | 최근 4H 6봉 중 1봉 이상 **종가 > BB(20,2) 상단** | 사상 ①·⑥ |
| **M3** | **정점 대비 하락 ≥ 8%** | **실측: 8% 미만 전부 적자** |
| M4 | 신고점 갱신 정지 ≥ 5봉(75분) | Fix 260 에서 독립 검증 |
| M5 | OBV 극단 상승 아님 | 사상 ④ |

**기록만** (진입 판정에 0점): 4H MACD hist 방향, 4H CCI 부호.
효과크기 2.08/2.00 이지만 그건 **종목 선정** 축이었고 반대매매 타이밍엔 −118~−145 였습니다.

### 4.3 🌟 승리 경로 (주 경로)

```
진입 후 이익이 가격 2.5% (ROI 5%) 에 도달할 때마다
  → 추가 자본 = 1시도 자본 × 0.5  (= 250)
  → 최대 2회
  → 추가할 때마다 손절 폭을 자본 비율만큼 축소 (손실 금액 고정)
```

**기존 `success_pyramiding_worker` 가 이미 ROI ≥ 5%(= 가격 2.5%) 트리거에 최대 2회**입니다 —
거의 최적값과 일치합니다. 다만 추가 자본이 「사다리 2칸」이라 전용 값이 필요합니다.

🚨 그 워커는 2026-08-30 에 볼밴 분할을 망가뜨린 전력이 있습니다(Fix 213, 4건 −252.18).
독립 SHORT 포지션에서 같은 사고가 나는지 구현 전 검증이 필요합니다.

### 4.4 패배 경로 (보조)

```
1시도 손절 → 대기 → M1~M5 재성립 → 2시도 (자본 1000, 가격 10%)
2시도 손절 → 대기 → 3시도 (같은 조건 = 500 / 가격 5% 복귀)
```

**승격은 무조건이 아닙니다** (사상 ⑦):
직전이 **손절로** 끝났을 것 / 심볼 누적 손실 상한 미만 / 계정 당일 손실 상한 미만 / preflight 통과

### 4.5 상태 저장 = **신규 DB 테이블** (alembic 0034)

🚨 **Redis 금지.** `docker-compose.yml` 의 redis 에 volume 도 `--appendonly` 도 없습니다.
재기동 한 번이면 카운터가 0 이 되어 **이미 크게 잃은 심볼에 다시 자본이 나갑니다.**

## 7. 사장님 결정 3가지

### ① 추가 규칙 — 수익 vs 안전

| 선택 | 건당 | 최악 1건 |
|---|---|---|
| **A** ×1.0 추가, 손실 고정 없음 | **+58.08** | **−650** |
| **B** ×0.5 추가, 손실 고정 없음 | +34.18 | −450 |
| **C** ×0.5 추가, **손실 고정** | +12.67 | **−250** (사장님 전제 준수) |

**제 권고는 C 로 시작해 실적 확인 후 B → A 로 올리는 것**입니다.

### ② 1단계 진입 — 「정점 대비 8% 하락」을 넣을까요?

넣으면 **−44.33 → +0.92**, 추가까지 붙이면 **+58.08**. 안 넣으면 어떤 조합도 적자입니다.

### ③ 자금 — 지금은 실행이 불가능합니다

```
가용 46.73 USDT  /  1시도 preflight 필요 525 (= 500 × 1.05)
```

🚨 특히 **가용 525~1,050 구간이 가장 위험**합니다 — 1시도는 들어가 손절되는데
2시도가 막혀 **손실만 확정되고 회수 기회가 없습니다.**
