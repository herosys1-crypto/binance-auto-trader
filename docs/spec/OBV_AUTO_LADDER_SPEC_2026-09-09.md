# 「새전략 OBV 자동」 운영 로직 확정판 (Fix 363, 2026-09-09)

> 사장님 (verbatim): "수동으로 10USDT 포지션 진입하고 손익이고 지속적인 손익이라 차트와 보조지표가 확실 할 때 300USDT 최대 2번 포지션 진입 나머지 지금 운영중이 새전략 인스턴스 옵션으로 운영하고 / 반대로 수동으로 10USDT 진입후 손실발생시 지속모니터링중 다시 이익이 가능한 포지션에서 300USDT 포지션 추가하고 그렇게 하고 다시 손실이 발행하면 10USDT만 남기고 부분손절하고 다시 모니터링후 이익이 가능한 구간에서 다시 600USDT 포지션 진입하고 수익과 손실이 발생하면 전략인스턴스 선택한 옵션으로 운영하는건데" → "기획서를 다시 검토하고 내가 요청한 시스템 로직으로 확실하게 정리해서 문제없이 개발을 마무리해줘"

기획서 v2.20 의 「기본전략(지정 트리거) / OBV 자동전략」 중 **OBV 자동** = 2·3단계를 가격이 아니라 신호로 넣는 사다리. 이 문서가 그 확정 사양이고, 9/9 검증([OBV_AUTO_FLOW_VERIFICATION](OBV_AUTO_FLOW_VERIFICATION_2026-09-09.md))에서 어긋난 곳을 Fix 363 으로 맞췄다.

## 3. 사장님이 알아둘 것
- 손실 조건 −5% 는 ROI 기준(2배에서 가격 −2.5%). 10 USDT 1단계면 손실 0.5 USDT 시점. 「손실이면 바로」로 하려면 `obv_stage2_loss_roi_pct=0`. 옛 화면의 「2단계 트리거 % −5」는 자동 OBV 템플릿의 가격% 이지 이 값이 아니다.
- 단계와 단계 사이엔 최소 15분(1봉)이 있고 직전 단계가 체결돼야 다음을 본다 — 평단이 갱신되기 전에 300→600 이 연쇄로 나가는 것을 막는다(반박 검증이 잡음).
- 「이익이 가능한 자리」 판정은 자동 진입과 같은 함수(OBV 게이트 + 15분 반복 극값·지표 꺾임 + SHORT 진입창)다. 이 판정 자체의 성적은 일지·가상 매매가 매일 잰다(정점 SHORT −0.26/건, 저점 LONG +0.86/건).
- 손절 래칫을 끈 대신, 추가한 만큼 −25% 손절 금액이 커진다(10+300+300 = 610 증거금 × 25% = −152 USDT). 이것이 「인스턴스 옵션대로」의 뜻이다.
- 모달의 2·3단계 트리거 % 칸은 OBV 모드에서 여전히 표시되지만 **주문에 쓰이지 않는다**(시장가). 화면 「단계 진입가」 표기는 다음 정리 때 없앤다.
