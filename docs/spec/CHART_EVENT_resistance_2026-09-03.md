### 1.2 접촉 판정 (15분봉, 종가 확정 시점)

```
high[i]  >= R * (1 - tol)
close[i-1] <  R * (1 - tol)              # 아래에서 처음 닿음
(close[i] / min(low[i-24..i]) - 1)*100 >= +1.0   # 올라와서 닿은 것만
tol = max(0.002, 0.25 * ATR14[i] / close[i])
쿨다운 6봉
```

### 1.3 라벨 (미래 96봉 = 24시간)

- 접촉 봉 **종가**에서 **+3% 선행 도달 → BREAKOUT(LONG 성공)**
- **-3% 선행 도달 → REJECT(SHORT 성공)**

🚨 **미결착 902건 + 같은 봉 양방향 동시도달 30건은 전부 제외**했다.

미래 96봉이 **전부 존재하는 봉만** 이벤트로 채택해 잘린 미래도 없앴다.

### 1.4 미래참조 차단

판정식은 접촉 봉 종가까지의 데이터만 쓴다. 상위 TF 는 **15분 봉 '시작시각' 이전에 확정된 마지막 봉**만 참조한다(`htf_state`). 즉 4H 봉이 진행 중이면 그 봉은 안 본다.

## 3. 실제로 통한 것 — 시장 전체 국면(breadth)

### 3.1 정의

> **breadth = 같은 15분 봉 종가 시점에, 감시 중인 상위 100종목(가용 97) 중 `15m close > EMA50` 인 종목의 비율**

동시점 관측치만 쓰므로 미래참조가 아니다. 운영 중 이미 100종목을 추적하므로 실시간 계산 가능하다.

### 3.2 단조 증가한다

| breadth | n | REJECT% | A그룹 | B그룹 |
|---|---:|---:|---:|---:|
| 0.00–0.25 | 686 | 41.4 | 45.7 | 36.6 |
| 0.25–0.40 | 1550 | **39.7** | 38.2 | 41.2 |
| 0.40–0.55 | 3551 | 46.4 | 46.7 | 46.1 |
| 0.55–0.70 | 2241 | **61.8** | 59.0 | 64.7 |
| 0.70–1.01 | 132 | **77.3** | 80.0 | 74.2 |

효과크기 **d = 0.313** (그룹A 0.264 / B 0.367).

**시간 5분할 검증**: `breadth>=0.55` 의 REJECT 율이 `breadth<0.40` 보다 높은가 → **5/5 구간 전부 참**
(77.1/43.6, 59.0/49.4, 60.7/39.5, 66.7/38.0, 52.4/30.3)

### 3.3 의미

시장 전체가 15m EMA50 위로 넓게 벌어져 있으면(breadth 높음) **저항은 막힌다**.
시장이 광범위하게 눌려 있으면(breadth 낮음) **저항은 뚫린다**.
→ 개별 종목의 되돌림이 아니라 **시장 전체의 되돌림**이 방향을 정한다.

## 7. 결론 못 낸 것

1. **`fib50` 저항선** 이 「24h 상승 종목 + ±3% 라벨」 문맥에서 OOS \|d\| **0.353**, 안정지표 8개를 냈다. 그러나 **153개 조합(정의×문맥×라벨) 중 1위**로 뽑힌 값이고 n=214 이며 시간축 검증을 안 했다. 선택편향인지 진짜인지 **결론 못 냄**.
2. **15분봉 5일치에는 국면이 2~3개뿐**이다. breadth 임계값 0.55 / 0.40 의 **절대값**은 이 표본에 맞춰진 것일 수 있다. 방향과 단조성은 5/5 구간에서 유지됐으나 숫자 자체는 30일 이상으로 재측정할 것.
3. **1시간봉에서 종목 지표 부호가 15분봉과 반대로 나온 이유**를 특정 못 했다. (a) 타임프레임 고유 성질인지 (b) 관측 기간이 달라 국면이 달랐던 것인지(15m 5일 vs 1h 21일) 이 데이터로는 분리 불가.
4. **breadth ≥ 0.70** 구간은 저항 132건 / 무작위 77건뿐. 승률 77.3% 로 최고지만 국면 수가 1~2개라 채택하지 않았다.
5. **사장님 ⑥번 「다시 상승 시점」의 진입 타이밍** — 돌파 확인 후 진입이 개선을 못 줬으므로, **돌파 후 되돌림(retest)** 에서 잡는 방식은 아직 안 재봤다.

## 8. 배선 시 주의 (Build 담당자용)

1. 🚨 **저항선 워커로 만들지 말 것.** 5장 대조군 참조. 국면 필터로 배선하고 저항선은 진입 가격 산정에만 쓸 것.
2. `market_breadth` 는 **공용 계산으로 한 번만** 구해 Redis 에 캐시할 것(15분 봉마다 1회). 종목별로 97번 재계산하면 낭비다.
3. 🚨 **breadth 가 결손이면 게이트를 '통과'로 두지 말 것.** 이 프로젝트는 결손 fallback 이 판정을 뒤집은 전력이 있다(Fix 296 — 청산가 결손 시 평단으로 대체해 LONG 재진입 조건이 정반대가 됐다). 결손이면 **명시적으로 '판정 불가'** 로 표시하고 기존 로직을 그대로 쓸 것.
4. `trend_4h_gate.py` 는 이 데이터로 **정당화되지 않는다**. 4H MACD 는 통과조건이 아니라 **가중치/표시용**으로 내릴 것을 권한다. 다만 이 분석은 「저항 국면」만 측정했으므로 다른 국면(정점 SHORT 등)에서의 효과는 별도 측정 대상이다.
5. 효과크기 **0.437(R4)은 이 프로젝트 기준 중간급**이다. `confluence.blocked` 의 -2.06 이나 4H MACD 방향의 2.08 과는 급이 다르다. **단독 진입 근거로 쓰지 말고** 기존 게이트에 얹는 가중치로 쓸 것.
