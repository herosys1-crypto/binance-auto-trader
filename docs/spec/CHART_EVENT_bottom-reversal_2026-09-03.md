## 2. 🚨 미래참조를 두 번 잡았다 — 둘 다 결론을 뒤집었다

이 보고서에서 가장 값진 부분이다. 두 건 모두 **처음엔 극적으로 좋은/나쁜 숫자**를 냈다.

### (1) `chg24` = 데이터 수집 시점의 24h 변동

첫 스캔에서 압도적 1위였다.

```
chg24 >= +4.93%    n=821  승률 0.566  기저 0.444  lift +0.123  효과크기 +0.247
                          A +0.113 / B +0.133   ← 교차검증도 통과
```

그런데 이 값은 **데이터를 받은 지금 시점**의 24h 변동이다.
5일 전 후보에 붙이면 그 후보의 **미래**를 쓰는 것이다.

진입 시점 기준(`chg24_pit = close[i]/close[i-96] - 1`)으로 다시 계산했더니

```
두 값의 상관계수 r = 0.154   (사실상 무관)
chg24_pit >= p50   n=730  승률 0.479  lift -0.052   ← 부호가 반대로 뒤집힘
```

**교차검증을 통과해도 미래참조는 잡히지 않는다.** 홀/짝 두 그룹 모두 같은 미래를 보고 있었기 때문이다.
→ `chg24` 는 전량 폐기하고 시점 기준 값만 썼다.

### (2) 2단계 연결에서의 미래참조 — 결론이 정반대로 뒤집혔다

「1단계 실패 → 더 낮은 새 저점 = 2단계」를 그대로 구현했더니

```
1단계 승률 0.616  vs  2단계 승률 0.312     (A -0.303 / B -0.304, 두 그룹 완벽 일치)
```

두 그룹이 소수점까지 일치해서 오히려 의심스러웠다. 원인은 연결 조건이었다.
**1단계의 손절이 확정되기 전에 나타난 후보까지 2단계로 세고 있었다.**
그것은 1단계를 죽이고 있는 바로 그 하락의 한복판이다 — 정의상 패배가 예정된 자리다.

`e2.i > e1.exit_i` (손절 체결 봉 이후) 조건 하나를 넣자

```
1단계 승률 0.497  vs  2단계 승률 0.546     (A +0.041 / B +0.058)
```

**부호가 뒤집혔다.** 사장님 2단계 전략은 실측으로 지지된다.

## 5. 🚨 반증 — 시도했다가 버린 것

### (1) 「지표가 아래에서 꺾여 올라올 때 진입」 — 반증

저점 반전의 교과서 조건인데, **저점 영역에서는 도움이 안 되거나 해롭다.**

| RSI(12) 상승 전환 | 1597 | −0.044 | +0.013 | −0.092 |

| 15m MACD hist 상승중 | 925 | +0.003 | +0.056 | −0.052 |
| 15m MACD hist 상승중 (2단계) | 476 | **−0.086** | −0.094 | −0.078 |

이미 지표가 올라오기 시작한 자리는 **반등의 첫 구간을 이미 내준 자리**다.
실제로 같은 방향의 증거가 세 개 더 나왔다: **몸통이 클수록 나쁘고**(body_ratio 상위 40% lift −0.081, 양 그룹 일치), **%B 가 높을수록 나쁘고**(lift −0.069), **아랫꼬리가 길수록 좋다**(lift +0.074, 양 그룹 일치).
→ **되받아친 흔적(긴 아랫꼬리 + 작은 몸통)은 좋고, 이미 올라간 몸통은 나쁘다.**

### (2) 🚨 사장님 「최저점을 여러번 반복」 — LONG 에서는 반증됐다

정점 SHORT 에서는 「여러번 반복 후 하락 시작」이 맞지만, **저점에서는 정반대다.**

|---|---|---:|---:|---:|---:|
| 저점 2회 이상 터치 | 1단계 | 684 | −0.032 | −0.073 | +0.011 |

2단계에서 효과크기 **−0.301**, 두 그룹 모두 음수다.
저점을 반복해서 찍는다는 것은 지지가 아니라 **매물이 계속 나오고 있다**는 뜻이다.
→ 채택 규칙에 `touch_40 <= 1` 을 **거부 조건**으로 넣었다(BOTTOM_L2_TOUCH_VETO).

**이것은 사장님 사상이 틀렸다는 뜻이 아니라, 정점 SHORT 의 조건을 저점 LONG 에 거울처럼 옮기면 안 된다는 뜻이다.**

### (4) 실전 BOTTOM 워커가 −6.72/건인 이유 — 생산자가 자리를 잘못 만든다

메모리 기록상 실전 저점 LONG 워커의 생산자는 **급락(−15%~−3%) 종목만** 만든다.

| −30% ~ −15% (더 깊은 급락) | 53 | **0.321** | 0.158 | 0.412 |

- 실전 생산자가 고르는 구간은 승률 0.516 으로 **기저(0.506)와 사실상 같고, 두 그룹이 어긋난다(0.551 vs 0.475)** — 우위가 없다.
- 더 깊은 급락은 **0.321** 로 재앙이다.
- **+3% 이상 상승 중인 종목의 조정**이 0.601 로 최고다.

→ 로직이 나빠서가 아니라 **후보를 만드는 쪽이 우위 없는 구간만 퍼 오고 있다.**

`chg48_pit > -0.080` / `chg24_pit > -0.058` 이 채택 규칙의 1순위 조건이 된 이유가 이것이다.

1. **`h4_close < 4H 볼밴 하단`** — lift +0.094 로 크고 두 그룹 다 양수지만 n=74(그룹당 38/36)로 얇다. 표본을 더 모으기 전엔 채택 보류.
