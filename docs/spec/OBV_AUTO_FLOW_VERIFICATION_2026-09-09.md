## 4. 지금 바로 할 수 있는 것 / 결정이 필요한 것

**설정만으로 (재시작 불필요)**
- `pyramid_sides=LONG,SHORT` — LONG 에도 300 추가 (A3).
- `pyramid_min_move_pct=2.5` — 추가 트리거를 실제 ROI 5 에 맞춤 (A2).
- `pyramid_cap_loss_enabled=0` — 추가할 때 손절 ROI 자동 하향 중지 (A4). 단, 이러면 추가한 만큼 손절 금액이 커진다(옵션 −25% 가 610 증거금에 그대로 적용 = −152 USDT).

**코드 수정이 필요한 것 (사장님 결정 후 제가 진행)**
1. OBV 2·3단계를 **신호 시점 시장가**로 (B2/B5, 한 줄). 지금은 「좋은 자리」에 신호가 떠도 시작가 ±10%/32% 지정가에 걸린다.
2. OBV 2단계는 **손실 중에만**, 정리 함수는 **이익이면 정리 안 함** (A5/B1). 죽은 키 `auto_obv_stage2_trigger` 를 그 조건으로 살림.
3. 부분손절 때 손절선·total_capital **복원** (B4).
4. 잔량 10 USDT 방치 방지: `TP1_DONE_PARTIAL` 도 단계 후보에 포함 + 잔량 대기 상한 (B7).
5. 화면 「전략 ROI」 분모를 투입 자본으로(계획 910 으로 나눠 91배 과소 표시).
