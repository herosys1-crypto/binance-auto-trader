# 전략 운영팀 (Fix 430) — 전략 교차 검증 · 장세별 배치 · 새 전략 편입 체계

> 사장님 2026-10-10: "새로운 전략들이 만들면 이것들을 서로 교차검증하고 서로 도움은 되는것을 같이 활용하는 전략으로 운영할수 있게
> 새로운 전략과 기존 전략을 상황에 맞게 운영할수 있는 분석과 운영팀을 구성하고 이들의 도움을 받아서 실패없는 자동매매가 될수 있게
> 운영할 방법을 만들어줘 계속 새로운 전략이 들어오면 그것도 그렇게 같이 활용해서 만들수 있게 해줘"

## 0. 먼저 솔직하게
「실패 없는 자동매매」는 만들 수 없다. 어떤 선택 정책도 장세가 뒤집히는 날 진다(아래 측정의 최악의 날 −6.56).
이 체계가 하는 일은 두 가지다.
1. **더 자주 이기는 칸만 쓰게 한다.** 무작위 대비로 재고, 장세별로 나누고, 미래 참조 없이 전진 검증한다.
2. **질 때 작게 진다.** 손실 상한 장치(가족 손실 차단기 Fix 384 · 자동매매 전면 중단 · 가족별 하루 최대 · 동시 보유 상한)를 그대로 둔다.

## 2. 성적표 (매일, `app/services/strategy_council.py`)
재료 = 가상매매 마감 행 최근 30일(`paper_trades`, source=live, engines.live.roi). 비교 기준 = 같은 날·같은 방향 무작위(`baseline_*`).
| 항목 | 뜻 |
|---|---|
| A 규칙별 | n · 평균 · **edge = 같은 날 무작위 대비** (시장 방향을 실력으로 착각하지 않게) |
| B 겹침 | 같은 봉에 같은 방향 규칙이 k개 켜졌을 때 — 서로 돕는가 |
| C 장세 | 시장폭(상승 종목 비율) low <0.4 · mid · high >0.6 별 무작위·전략 평균 |
| D 전진 검증 | 날짜 D 마다 [D−13, D−3] 성적으로 칸(규칙·방향·장세)을 골라 D 에 그 칸만 썼다면 — 미래 참조 없음 |
| E 오늘 쓸 칸 | 같은 방식으로 실행일(UTC) 칸 (지금 장세 칸이 먼저) |
| F 규칙 상태 | 표본 부족 / 사용 후보 / 중지 후보 / 관찰 — **새 전략은 가상 규칙에 등록되는 순간 자동 편입** |

칸 고르는 규칙: 학습창 n ≥ 30 · 평균 > 0 · 같은 장세 무작위 대비 edge > 0. 학습창의 절반 이상 날짜에 데이터가 있을 때만 채점.
설정(모두 「Claude가 정함」): `council_enabled` 1 · `council_days` 30 · `council_breadth_lo` 0.4 · `council_breadth_hi` 0.6 · `council_train_days` 11 · `council_gap_days` 3 · `council_min_n` 30.
결과: Redis `council:latest`(3일) · `council:day:YYYY-MM-DD`(120일) · 텔레그램 1통 · 화면 「🧑‍⚖️ 전략 운영팀 성적표」 카드 · `GET /api/v1/strategy-council/latest`.
