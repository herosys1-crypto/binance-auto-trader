## 1. 측정 설계 — 미래참조를 막기 위해 한 것

이 저장소는 "너무 좋은 결과는 미래참조를 의심하라"를 헌법에 넣을 만큼 데인 곳이라,
설계부터 적어 둔다.

| 항목 | 처리 |
|---|---|
| 진행 중 봉 | 로드 시점에 **모든 타임프레임의 마지막 봉을 제거**. 미완성 봉으로 판정하지 않는다 |
| 판정 시점 | 지표는 15m 인덱스 `i` 까지의 **완료봉만** |
| 4H 정렬 | 그 15m 시각에 **이미 완전히 닫힌** 4H 봉만 이진탐색으로 찾음 (`t4[m] + 4h <= t15[i]`) |
| 진입가 | `o[i+1]` — 다음 15m 봉 시가. 신호 봉의 종가로 진입하지 않는다 |
| 라벨 | TP/SL 선착 배리어. 기본 TP +3% / SL −3% / 최대보유 24h. 한 봉에서 양쪽 다 닿으면 **보수적으로 패** |
| **미결착** | 🚨 TP/SL 어느 쪽도 못 닿은 건은 **승률에서 제외**하고 별도 집계. 엄격신호 1,180건 중 결착 **1,027건(87.0%)**, 미결착 153건 |
| 교차검증 | 97종목을 이름순 정렬 → 짝수 인덱스 = **그룹A(49종목)** / 홀수 = **그룹B(48종목)**. 두 그룹 모두 기준 초과해야 채택 |
| 강건성 | TP/SL·보유시간 **7개 설정** + 신호 정의 **2종**(엄격/느슨)에서 전부 같은 부호일 것 |

> 오늘 다른 에이전트가 미결착 43.6% 를 승률에 섞어 극적인 값을 냈다가 정정한 사례가 있어,
> 미결착 비율을 먼저 확인하고(87.0% 결착) 제외 처리를 명시했다.

**15m 신호 정의** (사장님 사상: 정점 SHORT / 저점 LONG)

- 엄격 — 정점 SHORT: `%B[i-1] >= 1.0` (밴드 상단 밖) **AND** `%B` 하락 **AND** 종가 하락 **AND** `CCI(9) > +100`
- 엄격 — 저점 LONG: 대칭 (`%B[i-1] <= 0.0`, `CCI(9) < -100`)
- 느슨: `%B >= 0.9` / `<= 0.1`, CCI 조건 없음 (표본 3.5배)

## 4. 🏆 왜 그런가 — 2×2 로 갈라 보니 정확히 사장님 말씀이었다

같은 표본을 **4H EMA 배열(지속 상태)** × **4H MACD hist 1봉 방향** 으로 갈랐다 (SHORT, 501건).

| | hist 내 편으로 하락중 (게이트 통과 방향) | **hist 아직 안 꺾임** |
|---|---:|---:|
| **EMA 배열 내 편 (지속 하락)** | 49.3% (n=69) | **70.1% (n=157)** 🏆 |
| EMA 배열 반대 (지속 상승) | 51.4% (n=109) | 53.0% (n=166) |

축을 하나씩 고정해 보면 **상호작용**이 분명하다.

- **EMA 축**: hist 안꺾임일 때 EMA내편 70.1% vs EMA반대 53.0% = **+17.1%p**
  (hist 하락중일 때는 −2.1%p로 사라진다)
- **hist 축**: EMA내편일 때 하락중 49.3% vs 안꺾임 70.1% = **−20.8%p**
  (EMA반대일 때는 −1.6%p로 사라진다)

### 해석

- **EMA 배열**은 「이 흐름이 며칠째 지속되고 있는가」 = **상태**
- **MACD hist 방향**은 「지금 이 봉에서 가속도가 어느 쪽인가」 = **1봉 미분**

4H MACD hist 가 아래로 꺾였다는 건 **4H 급락이 이미 시작됐다**는 뜻이다.
거기서 SHORT 로 들어가면 늦다 → 49.3%.
반대로 4H 가 지속 하락 상태인데 hist 는 아직 위로 튀는 중(= 반등 중)일 때,
15분에서 밴드 상단을 찍고 꺾이면 **하락 추세 속 반등 실패**를 잡는 것 → 70.1%.

사장님이 말씀하신 4H 의 역할 —
> "**중단기 지속적인 흐름**을 판단하는 정도"

이게 정확히 **EMA 배열**이지 **hist 1봉 미분**이 아니다.

## 7. 🚨 연속 가중치 — 임무의 주 산출물

임무 지시: "산출은 **연속값(신뢰도 가중치)** 으로 내라. 이진 통과/차단으로 만들지 마라."

```
sgn = +1 (LONG) / -1 (SHORT)
trend_4h_score =   (ema20_4h*sgn > ema50_4h*sgn)          # 지속 상태
                 + (close_4h*sgn > bb_mid_4h*sgn)          # 지속 위치
                 + (hist_4h 가 내 편 반대로 꺾이지 않음)      # 아직 늦지 않음
                                                            # → 0 ~ 3점
```

| 0 | 62 | 48.4% | **×0.842** | 43.9% | 57.1% | OK |
| 1 | 148 | 52.7% | **×0.917** | 50.7% | 54.8% | OK |
| 2 | 198 | 55.6% | ×0.966 | 59.8% | 51.0% | **X** |
| 3 | 93 | **75.3%** | **×1.309** | 64.3% | 84.3% | OK |

기준 57.5%. **단조 증가 확인.** 다만 2점 구간만 교차검증 실패 → 배수 0.966 은 잠정값.

> 🚨 **최저 등급(0점)도 승률 48.4% 다. 막을 근거가 없다.**

### 🚨 10번에 대해 — 기존 사상의 한계

메모리에 "MACD 는 원시값 말고 **방향**으로 쓸 것"이 사상으로 박혀 있고,
Fix 270 문서에도 "4H MACD hist 「상승 중」 효과크기 **2.08**"이 최대 성과로 적혀 있다.

그런데 이번 측정에서 **같은 지표를, 같은 「방향」 사용법으로, 정점 SHORT 진입 맥락에 쓰니
부호가 뒤집혔다.** 이 저장소는 이미 "같은 지표라도 용도가 다르면 결과가 다르다"를
세 번 겪었는데(진입 vs 반대매매 vs 피라미딩), **네 번째 사례**다.

> **「방향으로 쓰면 항상 낫다」는 일반화가 틀렸다.**
> 「원시값 대신 방향」은 스케일 문제의 해법이지, 그 지표가 그 국면에 맞다는 보증이 아니다.
> 4H hist 방향은 **1봉 미분**이라 「지속 흐름」을 물을 때는 애초에 잘못된 도구다.

## 10. 결론 못 낸 것 (6건)

1. **LONG 의 연속 가중치.** 네 등급 전부 교차검증 실패, 단조성 붕괴. LONG 은 이진 규칙만 채택했다.
2. **SHORT 가중치 2점 구간**(n=198)이 교차검증 실패(A 59.8% / B 51.0%). 배수 0.966 은 잠정값.
3. **`TREND_4H_SHORT_STRONG`(3점)의 그룹간 편차**가 크다(64.3% vs 84.3%, n=93, 그룹당 약 45건). 표본 30건은 넘지만 최상위 배수 1.309 는 실거래 재확인이 필요하다.
4. **15m 데이터가 500봉(5일)뿐**이라 15m×4H 결합 측정이 최근 5일 국면에 갇혀 있다. 4H 단독은 83일이지만, 채택 규칙의 근거는 5일치다. **국면이 바뀌면 재측정 필요.**
5. **「보합」 판정을 별도 상태로 분리하지 못했다.** ADX<15 구간(n=818)에서 효과크기가 교차검증을 통과하지 못해 보합 전용 규칙을 만들 근거가 없었다.
6. **사다리 자본에서의 효과.** 실제 시스템은 분할 진입·부분 손절(10 USDT 잔량)·10/300/600 사다리를 쓰는데 본 측정은 단일 진입 + 대칭 배리어다. 사다리에서의 효과는 별도 측정이 필요하다.

## 11. 코드에 넣을 때 지킬 것

### 하지 말 것

- **4H 판정을 통과/차단(veto)으로 쓰지 말 것.** 사장님 명시이자 실측 근거(최저 등급도 48.4%).
- **LONG/SHORT 를 `sgn` 하나로 대칭 처리하지 말 것.** hist 조건이 서로 반대다.
- **MACD hist 원시값 금지.** 가격 단위라 심볼마다 스케일이 다르다. 부호와 방향만.

  (사장님이 두 번 강조하신 "추가는 +2% 가 아니라 **지속 상승/하락 데이터**"는 이 문서의 범위 밖이며,
   같은 지표라도 용도가 다르면 결과가 다르다는 것이 이 문서 자체의 발견이다.)

### 할 것

- `check_trend_4h` 의 hist 조건을 **EMA20/EMA50 배열**로 교체.
- 반환을 `(bool, str, dict)` 에서 **점수(0~3) + 배수**를 포함하도록 확장.
- 새 설정 키로 가중치 모드를 분리하고, `trend_4h_gate_enabled` 는 기본 OFF 유지.
