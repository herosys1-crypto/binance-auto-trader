> **[핵심 요약]**: 규칙(진입 신호)을 고르는 구조를 버리고 **「그날 LONG 이냐 SHORT 냐」를 정하는 방향 엔진 + 단순 진입 + 지정가 진입**으로 바꾼다. 방향 = 직전 24시간에 **이미 마감된** 무작위 기준 거래의 방향별 성적이 **나빴던 쪽**(역방향). 24개월 백테스트 기회당 +0.47 %p/건(지정가), 90% 하한 −0.05 — 우위가 얇아 **그림자(가상) 먼저**, 실주문은 사장님 결정.
> 착수 조건: ≈11/25 가설 N 전진 판정 통과(D-113). 이 문서는 판정 직후 바로 개발하도록 미리 쓴다.

## 2. 구성
### 2-1. 방향 판정 (순수 함수 · 매매 판정 코드 = 리드가 직접 작성, CLAUDE.md 규칙 3)
`services/direction_engine.py`
```
decide(closed: list[(side, closed_at, roi)], day_start_utc, *, window_h=24, min_n=20) -> "LONG" | "SHORT" | None
```
- 입력 = `paper_trades` source='live' · rule `baseline_LONG/SHORT` · status CLOSED · `closed_at ∈ [day_start − window_h, day_start)` · roi = `engines.live.roi`.
- 방향별 평균 roi 가 **낮은 쪽**을 고른다. 한쪽이라도 n < min_n 이면 None(그날 거래 안 함). 같으면 None.
- 🚨 미래 참조 금지: 진입일이 아니라 **마감 시각**으로 자른다(진입일 D−1 의 최종 roi 를 쓰면 D 일 가격이 섞여 +1.59 처럼 부풀었다 — 11/11 확인).
- 매일 00:05 UTC 1회 계산 → Redis `dir:engine:<YYYY-MM-DD>` (120일) `{side, n_long, n_short, m_long, m_short, at}`.

### 2-2. 가상 기록 (새 진입 없음 — 기준선 재사용)
- 무작위 기준선은 이미 `BASELINE_EVERY` 봉마다 상위 N 종목에 양방향으로 열린다. 엔진의 가상 성과 = **그날 엔진 방향 기준선 행**.
- 추가할 것: 기준선 행에 **지정가 진입 엔진 `live_lmt`** — 진입 종가에 지정가, `dir_limit_valid_bars`(기본 1) 안에 그 가격을 **뚫고 지나가야** 체결, 체결 봉 다음부터 `run_live_like` 청산. 미체결 = `{"filled": false}`.
- 비용: 시장가 0.40 · 지정가 0.24 %p (진입 0.02 + 청산 0.05 + 슬리피지 0.05, ×레버리지 2) — `paper_fee_pct`·`paper_slip_pct` 와 별도 키 `paper_maker_fee_pct`(0.02).

### 2-3. 성적표
- 운영팀 성적표(`strategy_council`)에 「방향 엔진」 줄: 날마다 엔진 방향 · 시장가/지정가 기회당 순수익 · 항상 LONG / 항상 SHORT 비교 · 체결률.
- 판정 스크립트 = `direction_contrarian_2026_11_11.py` (`FORWARD_FROM`) 그대로 + `live_lmt` 열.

### 2-4. 실주문 경로 (그림자 통과 + 사장님 승인 뒤에만 — 이번 범위 밖)
- 가족 `dir_engine` · 모드 `off|shadow|on` (기본 off → 개발 뒤 shadow, **on 은 사장님만**) · 관제실 한 줄.
- 진입 = post-only(GTX) 지정가 · 미체결이면 취소(쫓아가지 않음).
- 레버리지: 사장님 선호(10/21) — 청산 위험이 있으면 SHORT 1배 · LONG 위험하면 현물 · 가능하면 선물 양방향 안전하게.
- 손실 상한: 가족 차단기(7일) · 전면 중단 · 하루 최대 · 「작게 여러 건」(D-058).

## 4. 판정 기준 (사전 등록 — 바꾸지 않는다)
- ≈11/25 가설 N 전진(11/11~): 순수익/건 > 항상 SHORT · 항상 LONG · 날 평균 90% 하한 > 0 · 상위 3일 빼도 > 0 (D-113).
- 그림자 2주 뒤 실주문 권고 조건: 위 기준 + 지정가 실측 체결률 ≥ 85% + 기회당 순수익 > 시장가.
- 실패 시: 개편 v1 보류, 규칙 정리만(D-114).

## 5. 개발 경로·시험
- 경로: `workers/*`·판정 코드 → **/duel**(판정 함수는 리드가 직접) · UI·성적표 줄 → pair.
- 시험: `decide()` 속성 테스트(Hypothesis) — ① 마감 시각 ≥ day_start 인 행을 바꿔도 결과 불변(미래 참조 없음) ② LONG/SHORT 이름을 바꾸면 결과도 바뀜(대칭) ③ n < min_n 이면 None. 지정가 체결 함수 — 닿기만 하면 미체결 · 뚫으면 체결 · 유효 봉 밖 미체결.
- 배포 전: 서버..main 커밋 확인(04 교훈) · 다른 세션 실행 중이면 먼저 알림.
