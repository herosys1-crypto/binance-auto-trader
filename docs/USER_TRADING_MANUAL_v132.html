1️⃣ 자동매매 = 어떻게 작동?

1 사장님 = 「+ 새 전략」 클릭!
↓
2 1단계 진입: 시장가 or 지정가 자동!
↓
3 실시간 감시: 매 10초 = 가격 체크!
↓
4a 가격 상승 → TP1 → TP2 → TP3 → TP4 자동 익절!
4b 가격 하락 → 2단계 자동 진입 (평단 개선!)
↓
5 손실 -15% → 강제 SL 자동 청산!
↓
6 청산 후 재진입 ON이면 → 다음 단계 대기!
↓
7 Telegram 모든 이벤트 알림!

2️⃣ 신 전략 만들 때 = 뭘 세팅?

항목기본값설명
레버리지2x자율! 사장님이 원하면 = 1~125!
1단계 자본100 USDT진입 자본! (margin!)

2단계 트리거10%1단계 대비 -10% 시 = 2단계!
3+단계 트리거20%2단계 대비 -20% 시 = 3단계!
TP1/2/3/410/15/20/25%익절 임계 (수익률!)
TP qty10/15/20/25%각 TP = qty %!
TP1_override25%TP1을 이 %까지 대기! (사장님 옵션!)
강제 SL-15%손실 -15% 도달 = 자동 청산!
시작가비우면 MARKET!즉시 진입! (사장님 편의!)

💡 팁 (사장님 자율!):

  • 안전 매매: 레버리지 = 2x, 강제 SL = -15%!
  • 공격적 매매: 레버리지 = 5~10x, 강제 SL = -5%!
  • 장기 매매: 레버리지 = 2x, 강제 SL = 끔!

3️⃣ OBV 자동 재진입 (v130) = 언제 켜?

🎯 언제 사용?

OBV 흐름 = 반전 = 자동 재진입 원할 때!

클릭 방법:

대시보드 → 「📊 새 전략 (OBV 자동)」 클릭!

동작:

  1. 1단계 = MARKET 즉시 진입!
  2. 가격 하락 → 강제 SL 청산!
  3. OBV 자동 감시! (4H OBV + 15m/1h + 10% 이동!)
  4. 3조건 만족 = 자동 2단계 진입!
  5. 계속!

💡 OBV 사장님 언제?

  • ✅ 시장 = 상승 추세! (매수세 강함!)
  • ✅ 사장님 = 시간 없음! (자동 재진입!)
  • ❌ 하락장 = OBV 신호 안 옴! (기존 방식 나음!)

4️⃣ 청산 후 재진입 (v131) = 언제 켜?

🎯 언제 사용?

손절 후 = 청산가 대비 반등 대기!

= DCA (Dollar Cost Averaging) 강화!

클릭 방법:

신 전략 모달 → 레버리지 옆 「🔄 청산 후 재진입」 체크!

동작 (예시!):

  1. 1단계 500 USDT 진입!
  2. 손실 -15% → 자동 청산!
  3. [재진입 대기중!] 상태! (LIQUIDATED_WAITING_RETRY!)
  4. 청산가 × (1 - 10%) 도달 → 자동 2단계 진입!
  5. 계속!

⚠️ 주의 = 순차 진입!

재진입 ON = 절대 동시 보유 X!

= 1단계 청산 완료 후 = 2단계!

= 2단계 청산 후 = 3단계!

= 실용 = 2~3단계 한계! (사장님 정확!)

단계별 개별 트리거!

사장님 세팅 예:

단계트리거%이유
2단계10%기본 (빠른 재진입!)
3단계15%사장님 = 시장 분석 = 더 대기!
4단계20%사장님 = 많이 대기!

5️⃣ 차트 분석 (OBV / RSI / BB) = 어떻게 활용?

📊 OBV (On-Balance Volume)

= 매수/매도 세력!

  • OBV ↑ = 매수세 강!
  • OBV ↓ = 매도세 강!
  • OBV 반전 = 추세 반전 신호!

사장님 활용: OBV 반전 = 재진입 or 신 진입!

📈 RSI(14)

= 과매수/과매도!

  • RSI > 70 = 과매수 (하락 임박!)
  • RSI < 30 = 과매도 (반등 임박!)
  • RSI 반전 = 추세 전환!

사장님 활용: SHORT = RSI > 70! / LONG = RSI < 30!

📉 Bollinger Bands (BB)

= 20MA + 표준편차!

  • BB 상단 = 저항선!
  • BB 중단 (20MA) = 지지선/저항선!
  • BB 하단 = 지지선!

사장님 활용: 급등 후 BB중단 근접 = 매수 기회!

📊 EMA (Exponential Moving Avg)

= 이동평균 (지수!)

  • EMA(20/50/200)
  • 가격 > EMA200 = 상승 추세!
  • 가격 < EMA200 = 하락 추세!

사장님 활용: 추세 확인!

6️⃣ 알람 (재진입 / 급등BB) = 언제 확인?

🎯 재진입 알람 (강제 종료 후!)

조건: OBV + RSI + 10% 이동!

  1. 강제 종료된 심볼 (SL 발동!)
  2. 4H OBV 반전 + 4H RSI 반전!
  3. 손절가 대비 10% 이상 이동!
  4. → 사장님 대시보드 알람!

사장님 액션: 알람 클릭 → 신 전략 즉시 생성!

🚨 급등+BB중단 알람 (v131 신!)

조건: 24h 급등 top 50 + 4H 최고점 = BB중단 ±5%!

  1. Binance 급등 top 50 자동 스캔!
  2. 4H 최고점 계산!
  3. BB중단(20MA) 근접 (±5%)!
  4. → 사장님 대시보드 알람!

의미: 급등 후 = 조정 = 지지선 근접 = 매수 기회!

7️⃣ 사장님 매매 시나리오 (4가지!)

🎯 시나리오 A: 급등 종목 발견!

  1. 대시보드 「🚨 급등+BB중단 알람」 감지!
  2. 「🚨 BTCUSDT」 클릭!
  3. 신 전략 모달 = 심볼 자동!
  4. 방향 = SHORT (급등 후 반락!) or LONG (지지선 매수!)
  5. 자본 세팅 → 「✓ 진입」!

🔄 시나리오 B: 손절 후 재진입!

  1. SL 발동 → 청산!
  2. Telegram 알람 = 「강제 종료!」
  3. 4H 관찰!
  4. 「🎯 재진입 알람」 감지!
  5. 알람 클릭 → 신/구 방식 선택!
  6. 재진입!

⏰ 시나리오 C: 시간대 활용! (v132 신!)

  1. 대시보드 「⏰ Timezone 통계」!
  2. BTCUSDT = 새벽 03시 KST = 45% 급등!

  4. 02:50 = 「+ 새 전략」 대기!
  5. 03:00 = 급등 감지 → 진입!

🧠 시나리오 D: 자동 학습 활용! (v132 신!)

  2. 매 10분 = 유사 패턴 감지!

  4. 사장님 = 알람 → 검토!
  5. 진입 or 무시!

8️⃣ FAQ (자주 하는 질문!)

Q1: 「청산 후 재진입」 = 「OBV 자동 재진입」 차이?

청산 후 재진입 (v131): 청산가 기준 = 고정 % 도달 시 진입! (단순!)

OBV 자동 재진입 (v130): OBV 반전 감지 = 진입! (지표 기반!)

둘 다 켜기? = OBV 우선 (「📊 새 전략 (OBV 자동)」!)

Q2: 강제 SL은 언제 발동?

손실 = 사장님 세팅 % 도달 시!

중요: 다음 단계 남으면 = 발동 X!

= 마지막 단계 청산 후만 = 실 발동!

= 사장님 = 손실 회복 기회!

Q3: 130% 자본 경고 = 무슨 뜻?

총 세팅 자본 = 초기 자본 × 130% 초과!

= 여유 자금 30% 부족!

= 경고만! 진행 가능!

= 사장님 자율!

Q4: TP1_override는 뭐?

사장님이 = TP1을 몇 % 도달 시 발동할지 세팅!

= default = 10%!

= 사장님 옵션 = 25% (신 default!)

v132 신: TP1만 변경! TP2/3/4 = template 그대로!

Q5: 자동 실행 옵션 = 언제 켜?

지금 = 자동 실행 = 비활성!

= 안전장치 4개 미완성:

  • 4H 봉 완성 후 판정!
  • 중복 진입 방지!
  • 심볼 blacklist (연속 손실!)
  • RSI 극값 필터!

= 완성 후 = 소액 테스트 → 정식!
