### B 경로 숫자 워크스루 (진입 100, 레버 2, LONG, 계획 910, override 25, 라이브 설정)
1. **1단계** 10 USDT → qty 0.2 (명목 20). 손절 판정선 = 87.50(가격 −12.5% = ROI −25%). 87.5 도달: 판정 True(15초마다) → compute_trim: 목표 잔량 20 명목 ≥ 보유 17.5 → SKIP → 2단계 계획 있음 → **주문 없음, 잔량 유지**(RESIDUE_KEPT 시간당 1건). 이 상태는 ~50 USDT(거래소 청산)까지 무한정.
2. **2단계** OBV 신호(가격 무관, 예 87.5) → trim SKIP → 300 MARKET: qty 6.857, 총 7.057, 혼합 평단 **87.854**. `total_capital` 910 그대로, override 25 그대로(사다리 진입은 래칫 안 탐).
3. **2단계 손실** 평단×0.875 = **76.87** 에서 force SL → TRIM: 6.796 청산 / 0.261 잔여(명목 20.06, 증거금 ≈10.03). 실현손실 ≈ −74.6 USDT(6.796×(87.854−76.87)). 카운터 리셋. STOPPING 안 찍음. 15초 뒤 재판정 → SKIP → 3단계 대기.
4. **3단계** OBV 신호(예 80) → trim SKIP → 600 MARKET: qty 15, 총 15.261, 평단 **80.134**.
5. **3단계 손실** 80.134×0.875 = **70.12**: 첫 사이클 TRIM(14.975 청산 / 0.286 잔여) → 다음 사이클 SKIP + 다음 단계 없음 → **전량 청산 + STOPPING**. 실현 ≈ −150(3단계분) → 누적 ≈ −225 + 잔량분.
