## 4. 배운 것 (시스템 로직)

1. **정점 SHORT 의 상금은 실재하나 기계적 타이밍은 이 국면(19일 알트 상승 국면)에서 전부 진다.** 문제는 방향이 아니라 손절폭 대 진폭. 손절을 넓히면 승률만 오르고 기대값은 더 나빠진다.
2. **게이트 6개가 만든 「빈 창」**: 4H 게이트는 4H 가 꺾일 때까지 「이르다」고 막고, 꺾이면 Fix 350·regime 이 「늦다」고 막는다. 급등 5종 정점 뒤 통과 봉 0 은 우연이 아니라 구조다. 그런데 창을 열어도(게이트 제거) 기대값이 음수라 열 근거가 없다.
3. **사다리 2단계(300)가 손실의 심장**: 두 신호 방식 모두 2단계 −675/−1,980. 1단계 10 은 −32 로 「탐색 비용」에 불과하고 3단계는 양수. 9/3 과 같은 결론이 두 번째 표본에서 나왔다 → 2단계 자본 300 을 재검토할 근거(사장님 결정: 2단계를 3단계 조건(더 늦은 자리)으로 미루거나 자본을 줄이거나).
4. **급등 정점 사다리(Fix 267)는 그림자 성적이 −204/7일** → 사장님 「C → 실적 보고 B → A」의 실적 보고. B 로 올릴 근거 없음.
5. **실매매 조인이 가르쳐 준 것**(§7): 극값이 6h+ 뒤에 올 때 들어간 SHORT 가 −5,333 (수동 포함), 스냅샷 뒤 0~3h 진입 SHORT 13.9% 승. C 기타 LONG 6.0% 승 −779. A 사다리 FORCE_SL_DELAYED 51건 −994 = 손절이 떴는데 30분 넘게 안 나간 것(§8).
