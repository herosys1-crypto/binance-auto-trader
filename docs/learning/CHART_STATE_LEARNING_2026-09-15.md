## 1. 일봉 · 4시간 볼밴 상태 (볼린저 20·2, 완성봉만)

마지막으로 **닫힌** 봉 `i` 와 그 전 봉 `q` 로 판정한다. 「닿음」 허용 = 일봉 0.5% · 4시간 0.3%. 「돌파 뒤·이탈 뒤」 기억 = 일봉 5봉 · 4시간 6봉.
한 봉에 여러 이벤트가 동시에 참일 수 있어 `events` 에 전부 남기고, 대표 `state` 하나를 우선순위로 고른다.

| 사장님 말씀 | 코드 | 규칙 |
|---|---|---|
| 상단 돌파 | `UPPER_BREAKOUT` | 종가 > 상단, 전 봉 종가 ≤ 상단 |
| (지속 상승 중) 돌파 유지 | `UPPER_RIDE` | 종가 > 상단이 2봉 연속 |
| 상단 저항 | `UPPER_REJECT` | 고가가 상단에 닿고 종가는 상단 아래 (최근 돌파 없음) |
| 상단 돌파 뒤 조정 시작 | `PULLBACK_START` | 최근 5봉 안에 상단 밖 종가 → 지금 상단 안 + 전 봉보다 하락 |
| 상단 돌파 뒤 큰 조정 | `DEEP_PULLBACK` | 최근 10봉 안에 상단 밖 종가 → 지금 저가가 중단선까지 |
| 중단선 지지 | `MID_SUPPORT` | 전 봉 중단선 위 · 저가가 중단선에 닿음 · 종가 중단선 위 |
| 중단선 이탈 | `MID_BREAKDOWN` | 전 봉 중단선 위 → 종가 중단선 아래 |
| 중단선 돌파 | `MID_RECLAIM` | 전 봉 중단선 아래 → 종가 중단선 위 |
| 중단선 저항 | `MID_RESIST` | 전 봉 중단선 아래 · 고가가 중단선에 닿음 · 종가 중단선 아래 |
| 하단 이탈 | `LOWER_BREAKDOWN` | 종가 < 하단, 전 봉 종가 ≥ 하단 |
| 하단 이탈 뒤 추세 하락 | `LOWER_RIDE` | 종가 < 하단이 2봉 연속 |
| 하단 지지 | `LOWER_SUPPORT` | 저가가 하단에 닿고 종가 하단 위 (최근 이탈 없음) |
| 하단 이탈 뒤 반등 | `REBOUND_AFTER_LOWER` | 최근 5봉 안에 하단 밖 종가 → 지금 하단 안 + 전 봉보다 상승 |
| 재상승 시작점 | `RERISE_START` | 최근 10봉 안에 하단 이탈 또는 5봉 안에 중단선 닿음 → 종가 중단선 위 + 직전 3봉 고가 돌파 |

추가로 남기는 값: `trend`(중단선 3봉 기울기 일봉 ±1% · 4시간 ±0.5% = UP/DOWN/FLAT), `bias`(상승 이벤트 수 − 하락 이벤트 수),
`pos`(상단 밖·상단 절반·하단 절반·하단 밖), 상단·중단·하단까지 거리 %, 마지막 상단 밖·하단 밖 이후 봉 수.

> **「지속 상승에서는 지지·돌파·저항 뒤 재상승, 하락에서는 반대」** — 판정에 섞지 않고 `trend` 와 이벤트를 따로 기록한다.
> 보고서가 추세별로 갈라 보여 주므로, 같은 「중단선 지지」가 상승 추세와 하락 추세에서 결과가 어떻게 다른지 숫자로 확인된다.

## 2. 5분 · 1분 단기 고점·저점

직전 **확정** 고점(좌우 3봉보다 높음) = 저항, 직전 확정 저점 = 지지. 확정까지 3봉 늦다(미래참조 금지).
위치 창 = 5분 24봉(2시간) · 1분 60봉(1시간). 「닿음」 허용 0.15%.

| 코드 | 뜻 | 규칙 |
|---|---|---|
| `RESIST_REJECT` | 저항 반락 | 고가가 직전 고점에 닿고 종가는 그 아래 + 음봉 |
| `BREAK_RESIST` | 저항 돌파 | 종가 > 직전 고점, 전 봉은 아래 |
| `SUPPORT_HOLD` | 지지 반등 | 저가가 직전 저점에 닿고 종가는 그 위 + 양봉 |
| `BREAK_SUPPORT` | 지지 이탈 | 종가 < 직전 저점, 전 봉은 위 |
| `NEW_HIGH` / `NEW_LOW` | 창 안 신고가 / 신저가 | |
| `ROLLOVER` | 고점 뒤 꺾임 | 최근 3봉 안 신고가 → 종가가 전 봉 저가 아래 |
| `REBOUND` | 저점 뒤 반등 | 최근 3봉 안 신저가 → 종가가 전 봉 고가 위 |
| `BEAR_DIV` / `BULL_DIV` | 다이버전스 | 고점은 높아졌는데 RSI 는 낮아짐 / 반대 |
| `near_top` / `near_bottom` | 단기 고점권·바닥권 | 위치 ≥ 0.85 + RSI ≥ 65 / 위치 ≤ 0.15 + RSI ≤ 35 |

## 3. 모든 시간봉 공통 보조지표

볼밴 상단·중단·하단 · %B · 밴드 폭 % · 중단선 3봉 기울기 · RSI14(현재·직전) · MACD 히스토그램(현재·직전·방향) ·
EMA20/50 배열(UP/DOWN/MIXED) · ATR14 % · 거래량 20봉 배수 · 마지막 봉 변동 %.

## 4. 진입 타이밍 채점 (진입 전 1시간 + 진입 뒤 4시간, 5분봉, 가격 %)

| 라벨 | 뜻 | 규칙 (먼저 걸리는 것) |
|---|---|---|
| `WRONG_DIRECTION` | 잘못된 방향 | 3% 역행이 1.5% 순행보다 먼저 + 4시간 뒤에도 손실 쪽 |
| `EARLY` | 빠른 진입 | 결국 1.5% 순행했지만 그 전에 1.5% 이상 먼저 역행 |
| `GOOD` | 좋은 진입 | 1.5% 순행, 그 전 역행 1.5% 미만 |
| `LATE` | 늦은 진입 | 1.5% 순행 없음 + 진입 전 1시간 안에 2% 이상 더 좋은 가격이 있었음 |
| `NO_MOVE` | 움직임 없음 | 그 밖 |

`best_offset_bars` = 그 5시간 창에서 방향상 가장 좋은 가격이 나온 봉 − 진입 봉 (음수 = 이미 지나감 · 양수 = 더 기다렸어야).
`best_improve_pct` = 그 가격이 진입가보다 얼마나 좋았나.

## 5. 보고서 읽는 법

`/api/v1/paper-trading/chart-state.md`:
- ① 일봉 볼밴 상태 × 방향 — 규칙 진입 평균 ROI 와 **같은 상태의 무작위 진입(기준선)** 평균, Δ, 4조각(심볼 홀짝 × 기간 전후반) 중 Δ>0 수.
  예: `LONG · 중단선 지지` Δ가 크고 4/4 이면 「일봉 중단선 지지에서의 LONG 은 무작위보다 낫다」.
- ② 일봉 추세 × 방향 · ③ 5분 위치 × 방향 — 「고점권에서 LONG」·「바닥권에서 SHORT」 같은 늦은/잘못된 자리가 드러난다.
- ④ 가상 진입 타이밍 라벨 분포와 라벨별 평균 ROI · ⑤ 실거래 타이밍 라벨.

## 6. 설정 (재시작 불필요)

| 키 | 기본 | |
|---|---|---|
| `chart_state_enabled` | 1 | 가상·실거래 기록과 타이밍 채점 전체 |
| `chart_state_1m_enabled` | 1 | 1분봉 조회 (사장님 「필요하면 1분차트까지」) |
| `chart_state_thresholds` | 없음 | JSON 으로 위 숫자 덮기 (예 `{"tol_pct_1d": 0.8, "timing_win_pct": 2}`) — 모두 「Claude가 정함」 |

## 7. 한계

- 가상매매는 **규칙이 발동한 순간**에만 기록한다 (감시 399종목 전부를 매 사이클 조회하지 않는다 — API 부담). 백필 행에는 없다.
- 실거래 기록은 진입 뒤 15분 안에 학습 동기화가 잡은 건만 (그 뒤는 「지금 차트」라 붙이지 않는다).
- 단기 고점·저점은 확정까지 3봉(5분 15분 · 1분 3분) 늦다. 판정 규칙의 숫자는 첫 버전 — 보고서를 보고 조정한다.
- 타이밍 채점은 가격 % 기준(레버리지 무관) · 수수료 제외 · 진입 4시간 창만 본다.
