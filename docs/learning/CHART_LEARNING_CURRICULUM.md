## 1. 장치 (매일 자동으로 쌓인다)

- **스냅샷** (UTC 00:05 = KST 09:05, 일봉 마감 직후): 당일 상승 50·하락 50 ∪ 3일·5일 상승 50·하락 50 → 심볼별 15m 200봉 + 4h 61봉 + 지표를 **그 시각 기준 완성봉만** 저장. 한 심볼에 여러 태그(예: `UP5D`+`DOWN` = 며칠 상승 뒤 당일 조정).
- **라벨링** (매시간): 36h 지난 행에 결과 15m 144봉을 붙이고 「자리의 값」(정점·저점까지 시간, 정점 뒤 12h 낙폭, 저점 뒤 반등)과 **규칙별 첫 충족 봉의 결과**(레버 2 · SL −5% · TP +15% ROI · 12h)를 계산.
- **보고서**: `python -m app.workers.chart_learning_worker report --days 60` 또는 `GET /api/v1/chart-learning/report.md`.
- 되돌리기: `chart_learning_enabled=0` (재시작 불필요). 표: `chart_learning_days` (라벨은 영구, 원시 봉은 45일).
- 미래참조가 **구조적으로 불가능**한 이유: 감시 대상이 스냅샷 시각에 확정되고, 결과는 그 뒤에만 붙는다. 9/3 에 4번 잡은 「과거 봉에 오늘 순위를 붙이는」 함정이 생길 자리가 없다.

## 2. 채택 규칙 (사람이 한다 — 자동 튜닝 없음)

1. 규칙은 먼저 레지스트리(`chart_learning.RULES`)에 **후보(candidate)** 로 넣고 라벨이 쌓이길 기다린다.
2. 교차검증 네 조각(심볼 짝/홀 · 날짜 전/후반)이 **전부 기준선보다 양수**이고 n ≥ 100 이면 후보 → 사장님 보고.
3. 배선은 설정키와 함께, 전략 가족별로(A 사다리 / B 볼밴 / C 기타), 공용 경로에 넣지 않는다.
4. 배선 뒤에도 매일 재측정 — 뒤집히면 설정으로 끈다.

- **재사용** — 규칙 정의(①), 기준선 개념, 태그 그룹(자리), 교차검증 4조각(심볼 짝/홀 × 시간 전/후반),
  n≥100·Δ>0 채택 문턱을 그대로 가져온다. 새로 만들지 않았다.

  같은 포지션 위에서 동시에 측정한다 — Day 5 가 묻던 질문에 대한 첫 실측 장치.
