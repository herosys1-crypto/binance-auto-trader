## 2. 그래서 세운 가설 — 그리고 **기각**

가설: 「24h 급등(+10% 이상) + 1시간 되돌림(−5% 이하) → LONG」

| 대상 | 발견 기간 (9/9~9/13) | 검증 기간 (9/14~9/18) | 판정 |
|---|---|---|---|
| 상승 초입 LONG | 무작위 대비 **+9.62** (n19) | **−5.01** (n27) · 5일 중 양수 0일 | ❌ 뒤집힘 |
| LONG 규칙 합산 | +0.97 (n333) | **−2.02** (n346) · t −2.0 | ❌ |
| 무작위 LONG | — | **−4.69** (n92) | ❌ |
| 기존 게이트에 이 가지를 더하면 | ex +1.13 → +1.20 | ex **+0.69 → +0.51** · ROI +2.51 → +2.35 | ❌ 더 나빠짐 |

**그 +21.7% 는 운이었다.** 같은 자리를 규칙으로 만들면 검증 기간에 손해였다. 그래서 채택하지 않았다.
(사장님이 「한 건이라 판단 근거로 쓰지 않습니다」라고 하신 그대로였다.)

## 3. 두 기간 모두 통한 것 = 완성한 조건

상승 초입 LONG 1,239건(발견 762 · 검증 477)을 구간별로 갈라, **발견과 검증에서 방향이 같은 것만** 남겼다.

| 구간 | 발견 (무작위 대비) | 검증 | 일치 |
|---|---:|---:|---|
| 24h **0~+5%** (미동) | −0.72 | −0.76 | ✅ 둘 다 손실 |
| 24h **+20~40%** (과열) | −3.53 | −3.20 | ✅ 둘 다 손실 |
| 24h +40% 이상 | +6.35 | −5.11 | ❌ 불안정 → 막는 쪽으로 |
| 1시간 고점 **−1.5% 이내**에서 진입 (추격) | −1.84 | −0.60 | ✅ 둘 다 손실 (신호의 48%) |
| 1시간 고점 −5~−3% | +0.16 | +1.10 | ✅ 둘 다 이득 |

**채택 조건 (셋 다 「하지 말 것」)**
1. **1시간봉 16개 고점에서 −1.5% 이하로 내려와 있을 때만** 진입 (고점 바로 밑 추격 금지)
2. **24h 변동 +20% 미만** (과열 금지)
3. **24h 변동이 0~+5% 구간이면 건너뜀** (미동 구간)

| | 발견 기간 | 검증 기간 |
|---|---|---|
| 통과 비중 | 32% | 31% |
| 통과 평균 ROI | −1.65 | **+3.08** |
| 막힌 쪽 평균 ROI | −1.98 | −0.24 |
| 통과 무작위 대비 | −0.87 | **+2.19** |
| 막힌 쪽 무작위 대비 | −1.13 | −1.07 |
| 승률 | 46% | 59% |
| 날짜별 양수 | 2/5일 | **5/5일** |

- 발견 기간에는 「통과가 막힌 쪽보다 낫다」 정도였고(둘 다 손실), 검증 기간에 확실히 갈렸다.
- 옛 방향 공통 조건만 쓰면 이 가족은 **10%** 만 남고 검증 무작위 대비 +0.07 에 그친다 → 가족 전용 조건이 낫다.
- 검증 기간 막힌 이유: 1시간 추격 228건 · 24h(과열·미동) 211건 · 차트 값 없음 12건.
- ⚠️ 이 조건은 **이 가족에서만** 두 기간이 일치했다. 무작위 진입에는 발견 기간에 반대였다 → 일반 규칙으로 쓰지 않는다.
- 🚨 **위 AVAUSDT 건은 새 조건에서도 막힌다** (24h +38.6% = 과열). 그 자리를 열려면 과열 문턱을 올려야 하는데, 과열 구간은 두 기간 모두 손실이었다.
