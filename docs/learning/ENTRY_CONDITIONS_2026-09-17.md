- **SHORT 가 진 이유 = 이미 떨어진 뒤에 쫓아 들어간 것.**
  - 「정점 대비 −8%」·「20봉 신저점 이탈」이 대표적이다.
  - 고점 근처에서, 일봉이 오르지 않을 때만 들어가면 된다 — 사장님 원칙 「급등 정점 SHORT」 그대로다.
- **LONG 이 진 이유 = 오르는 중에 추격한 것.**
  - 일봉 상단 돌파 뒤 LONG 이 가장 나빴다.
  - 급락·조정 뒤에만 들어가면 된다 — 사장님 원칙 「LONG = 급락·조정 뒤」.
- ⚠️ **LONG 은 걸러도 절대 수익이 0 근처다.** 기간이 하락장이었다.
  - LONG 은 이 게이트만으로 켜지 말고, 7일 재판정과 국면(MKT_UP) 확인을 같이 본다.
- 🚫 **1시간 변동성이 낮을 때**는 방향에 따라 결과가 반대다.
  - SHORT 에는 좋다(+3.4).
  - LONG 에는 나쁘다(검증 −0.90 vs +1.19).

## 2. 어떻게 찾았나 (과적합 방지)

**데이터와 재계산**
- 가상매매 실시간 진입 **22,652건** (9/9~9/16, 규칙 20개 + 무작위 기준선 2개)을 썼다.
- 진입마다 **진입 시점에 이미 닫힌 봉만으로** 일봉·4시간·1시간·5분 `chart_state` 를 운영 코드 그대로 다시 계산했다.
  - 봉은 로컬 IP 에서 바이낸스 공개 API 로 받았다 (408 심볼).
  - 운영 기록이 있는 893건과 값이 **정확히 같다** (일봉 상태 일치 97%, 나머지 3% 는 한쪽이 빈 값).

**발견과 검증을 나눴다**
- **발견** = 사전등록 이전(9/9~9/13 22:16) · **검증** = 이후(9/14~9/16).
- 조건은 발견 기간에서만 고르고, 검증 기간은 고른 뒤에만 봤다.

**규칙마다 따로 고른 조건은 대부분 검증에서 뒤집혔다** (= 우연)
