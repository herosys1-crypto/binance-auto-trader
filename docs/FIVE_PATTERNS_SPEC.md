## 📊 5가지 패턴 상세 (지표 모양!):

### 🟢 A. **급등 시작 (INITIAL_SURGE)** = LONG!
```
가격 (BB):     ─────↗ 볼밴 상단 근처 돌파 시작!
RSI:          40 → 60~70 (상승 진행!)
CCI:          -50 → +100 (반전!)
OBV:          급상승 (매수 폭발!)
MACD:         hist 상승 반전 (골든 크로스!)
volume:       평균 2~5배!
15m:          최근 3봉 = 강한 양봉!
1h:           반등 시작!
4h:           볼밴 중단 위 이동 시작!
change_24h:   +10~20% (아직 초기!)
```
→ **LONG 진입!** (아직 상승 여지 큼!)

---

### 🟠 B. **급등 후 하락 시작 (SURGE_DROP_START)** = SHORT!
```
가격 (BB):     ↗↗ 최고점 → ↘ 첫 하락!
RSI:          80~90 (극과매수!) → 70 하락!
CCI:          +200 → +100 하락!
OBV:          정점 → 살짝 하락!
MACD:         hist 감소 (음전환 임박!)
volume:       고점 큰 봉 → 하락 시작!
15m:          최근 1~2봉 = 첫 음봉!
1h:           약한 하락!
4h:           볼밴 상단 저항!
change_24h:   +30~50% (고점!)
```
→ **SHORT 진입!** (하락 초기!)

---

### 🔴 C. **급등 후 급락 (SURGE_CRASH)** = SHORT 강!
```
가격 (BB):     ↗↗ → ↘↘↘ 볼밴 중단 하향 이탈!
RSI:          90 → 40~50 (급하락!)
CCI:          +200 → -100 급하락!
OBV:          급하락 (매도 폭발!)
MACD:         hist 강한 음전환!
volume:       하락봉 = 상승봉 2~3배!
15m:          최근 3봉 = 강한 음봉!
1h:           강한 하락!
4h:           볼밴 중단 이탈 확정!
change_24h:   여전 +20% 이지만 최근 6h = -20%!
```
→ **SHORT 강!** (지속 하락 예상!)

---

### 🟢 D. **급등 후 조정 → 재상승 (SURGE_PULLBACK_RESUME)** = LONG (조정 후!)
```
가격 (BB):     ↗ 급등 → 3~5봉 조정 → ↗ 재상승!
RSI:          70 → 40~50 (조정!) → 55~65 (재상승!)
CCI:          +150 → 0 → +80 반등!
OBV:          급상승 → 유지 → 다시 상승!
MACD:         hist 감소 → 다시 증가!
volume:       조정 시 감소 → 재상승 시 증가!
15m:          최근 5봉 조정 → 최신 2봉 강한 양봉!
1h:           볼밴 중단 지지!
4h:           볼밴 방향 = 여전 상승!
change_24h:   +20% (조정 완료!)
```
→ **LONG 진입!** (조정 후 = 신 상승!)

---

### 🔴 E. **급등 후 급락 → 반등 → 재급락 (FAKE_BOUNCE_CRASH)** = SHORT (반등 후!)
```
가격 (BB):     ↗ → ↘↘ → ↗ (짧은 반등!) → ↘↘ 재하락!
RSI:          90 → 30 (급락!) → 50 (반등!) → 40 (재하락!)
CCI:          +200 → -150 → +50 (반등!) → -100 (재하락!)
OBV:          급상승 → 급하락 → 살짝 상승 → 다시 하락!
MACD:         hist 음수 → 잠깐 양수 → 다시 음수!
volume:       하락봉 > 반등봉 (매도 압력 여전!)
15m:          최근 5봉 = 반등 실패 (긴 위꼬리!)
1h:           반등이 볼밴 중단 못 넘음!
4h:           볼밴 방향 = 하락!
change_24h:   여전 +10% 이지만 최근 12h = -30%!
```
→ **SHORT!** (반등 실패 = 큰 하락!)

## 🎯 감지 로직 (요약!):

### 공통 조건:
- 24h 변동 최소 = **+10%** (급등 심볼만!)
- volume_24h >= 5M USDT (거래 활발!)
- 학습 인사이트 = worst 심볼 제외!

### A vs B 구분:

- B: change_24h 30%+ + RSI 75+

### C vs D vs E 구분:

- D: 조정 완료 (3~5봉 후 상승 재개)
