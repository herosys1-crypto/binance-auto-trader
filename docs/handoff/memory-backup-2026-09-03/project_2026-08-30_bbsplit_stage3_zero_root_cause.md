# 2026-08-30 볼밴 3차 0건 — 진짜 원인 (Fix 209~212)

브랜치 `claude/infallible-euler-6dc297` (`5242685`). PR 미머지 상태로 세션 종료 가능.

## 🚨 사장님 질문 "볼밴 전략이 없는데" 의 답 = **화면**

[index.html:1663](backend/app/static/index.html) 「종료 숨김」이 **기본 `checked`**.
볼밴 17건이 전부 `STOPPED`(12)/`COMPLETED`(5) 라 **전부 숨겨졌다.** 없는 게 아니었다.
워커는 15분마다 정상 동작 중이었다 (`후보 9~12 / 진입 0 / 사유 no_break`).

## 📊 볼밴 실적이 말해준 것

| | 건수 | 실현 |
|---|---|---|
| `COMPLETED` (완주) | 5 | **+330.41** — **5건 전부 흑자** |
| `STOPPED` (강제손절) | 12 | −369.47 — 11건 적자 |

**전략이 나쁜 게 아니라 −10% 까지 버티게 두질 않았다.** 단계체결 1/3=12, 2/3=5, **3/3=0**.

## 🎯 원인 ① — 1차 **시장가 체결가**가 2차 트리거와 겹친다 (Fix 209)

1차는 `IMMEDIATE`. 「기준선 −3% 도달」을 감지한 **그 순간** 가격에 체결된다.
15분 주기 사이 더 빠지면 1차가 −5.5% 에 체결되고, 기준선 기준으로 미리 깔아둔
2차(−5%)는 **이미 지나간 가격**이 된다.

```
#1639  1차 -5.49% / 2차 -5.01%   = 2차가 1차보다 위 = 태어날 때 이미 죽음
#1727  1차 -5.02% / 2차 -5.03%   = 간격 0.01%p = 사실상 같은 자리
```

사장님 선택(**「b」**): 앵커를 기준선 → **실체결가**. 간격은 원 설계 그대로.
`reanchor_from_fill()` 을 `stage_trigger_worker`(15초)에서 매번 호출.
2차가 체결되면 3차는 2차 체결가에서 다시 깐다.

🚨 **함정**: `compounded_trigger_pcts` 는 앵커가 **기준선**이라 2차가 **5.00%** 로 나온다
(계산기가 `start_price` 부터 복리로 접기 때문). 재앵커는 「1차 대비」가 필요해
`stage_gap_pcts` 를 새로 만들었다 — 3/5/7 → **2.06% / 2.11%**.
**처음에 compounded 를 그대로 썼고 테스트가 잡았다.**

## 🎯 원인 ② — 「긴 추세(중단선)」 모드는 **진입이 수학적으로 불가능**했다 (Fix 212)

- `_is_long_trend` — LONG 은 **현재 봉 포함** 6봉이 전부 `종가 > 중단선` 이어야 참
- `_entry_plan` — 참이면 `base=중단선`, 진입은 `종가 ≤ 중단선 × 0.97`

같은 봉이 중단선 위이면서 동시에 3% 아래일 수는 없다.
사장님 확정 "볼밴 중단은 지속 상승일때 같은 전략으로" 가 **한 번도 안 돌았다.**
→ 추세는 **직전 6봉**으로 보고(현재 봉 제외) 눌림목에서 산다. `range(2, BARS+2)`.

## 🎯 원인 ③ — **피라미딩이 볼밴 평단을 반대로 밀었다** (Fix 213) ★ 가장 큰 건

```
#1711  볼밴 1차   399개 @0.50110  (100 USDT)
       피라미딩  1146개 @0.52345  (300)   ← 더 비싸게
       피라미딩  1119개 @0.53621  (300)   ← 더 비싸게
       평단 0.50110 → 0.52546  (물량 5.7배)
       → 손절선이 **1차 진입가보다 위**. 진입가로 되돌아오기만 해도 -10% 손절.
```
#1721 / #1699(SHORT) / #1629 동일. **4건 합계 -252.18** (볼밴 전체 실현 -39.06).
**이것만 없었으면 볼밴은 크게 흑자였다.**

범인 식별: `client_order_id = {SYM}_ADHOC_M_{hex}` + `ADD_POSITION_TP_RESET` +
추가 자본 **매번 정확히 300.0** + 주문 시각이 **30초 그리드** +
발동 조건 `ROI >= 5.0` (`max_profit_pct` 6.83/5.91/4.10 과 일치)
→ **`success_pyramiding_worker`**. `split_entry` 제외 코드가 **없었다**.

🚨 **결정타**: 볼밴 TP1 은 ROI **+5% 부터 익절**인데 피라미딩 발동선도 **ROI +5%**.
익절해야 할 바로 그 지점에서 추가 매수가 나간다. 게다가 `mode=reset` 이라
`max_profit_pct` 가 지워진다(#1629 +6.83% → None) = 트레일링 익절까지 리셋.

fix: 후보 쿼리에서 `capital_management_mode == "split_entry"` 제외 + 루프 안 재확인.
다른 전략 피라미딩은 그대로 둔다. `SPLIT_ENTRY_MODE` 문자열이 `MODE_MARKER` 와
어긋나면 조용히 새므로 **테스트로 고정**했다.
