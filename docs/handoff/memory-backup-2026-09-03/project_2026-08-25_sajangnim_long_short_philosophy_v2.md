## 🎯 LONG 진입 4대 시나리오:

### 1️⃣ **급락 후 반등 시점** ⭐
- 하락 지속 → 매도 압력 소진 → 반등 시작!
- 시그널: OBV 반전 상승 + RSI 30 이하 → 상승 + 볼륨 급증
- Fix 62/64 (급락 감지) 반전 신호와 연결!

### 2️⃣ **장기 하락 후 BB 하단 지지 or 돌파 확인** ⭐
- **핵심**: "확인된" 시점만! (기다림!)
- BB 하단 터치 → 반등 시작 (지지 확인!)
- BB 하단 돌파 → 재진입 → 상승 전환 (돌파 후 확인!)
- 시그널: 하단 3회 이상 지지 or 하단 아래 wick + close 하단 이상

### 3️⃣ **급등 후 조정 = BB 중단 지지** ⭐
- 급등 → 조정 (5~10%) → BB 중단(SMA20) 도달 → 지지 확인!
- 상승 추세 유지 + 볼륨 감소 후 다시 증가!
- LONG 재진입 = 상승 지속 시!

### 4️⃣ **급등 후 조정 = BB 하단 지지**
- 급등 → 큰 조정 (10~20%) → BB 하단 도달 → 지지!
- 반등 시작 → LONG 진입 (2~3% 반등 확인!)

- **⭐ 이미 있는 전략!** = `success_pyramiding_worker` (Fix 4/17 배포됨!)
- **⭐ 초기진입 설정된 금액 그대로!** = 마틴게일 배수 X!

### 🌟 3️⃣ **전체 하락 전환 → 지지/저항 지속 수익!** ⭐
- **사장님 verbatim**: "지속적으로 수익을 만들어가는거야"

- **전략**: 각 저항 지점마다 SHORT + 각 지지 지점마다 LONG!
- **자동**: 볼밴 상단 = SHORT / 볼밴 하단 = LONG!
