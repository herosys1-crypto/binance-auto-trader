## 📊 MACD 3가지 핵심 요소:

### **1. MACD 선 (Fast!) - 핑크색:**
- 계산: **EMA(12) - EMA(26)**
- **의미**: 단기 vs 장기 이평선 차이!
- **상승** = 단기 강세 시작!
- **하락** = 단기 약세 시작!

### **2. Signal 선 (Slow!) - 보라색:**
- 계산: **MACD 선의 EMA(9)**
- **의미**: MACD의 평균 흐름!
- MACD 선 = 빠른 반응!
- Signal 선 = 느린 반응 (지연!)

### **3. Histogram (막대!) - 초록/빨강:**
- 계산: **MACD - Signal**
- **의미**: MACD와 Signal의 격차!
- **초록 (양수!)** = MACD > Signal = **상승 힘!**
- **빨강 (음수!)** = MACD < Signal = **하락 힘!**
- **크기** = 힘의 강도!

## 🎯 MACD 8가지 신호 (완벽!):

### **📈 상승 신호 (LONG!):**

**1. 크로스오버 (Golden Cross!) ⭐**
- MACD 선이 Signal 선을 = **위로 돌파!**
- Hist = 빨강 → 초록 전환!
- **=> 강력 LONG 신호!**

**2. 히스토그램 반전:**
- Hist 감소 (빨강 작아짐!) → 증가 (양수 커짐!)
- **=> 힘의 반전! LONG 준비!**

**3. Hist 지속 확대 (초록 커짐!):**
- 상승 힘 지속 증가!
- **=> LONG 지속!**

**4. MACD 저점 형성:**
- 하락 중 MACD 선이 저점 만들고 반등!
- **=> 반전 시작!**

### **📉 하락 신호 (SHORT!):**

**5. 크로스오버 (Dead Cross!) ⭐**
- MACD 선이 Signal 선을 = **아래로 돌파!**
- Hist = 초록 → 빨강 전환!
- **=> 강력 SHORT 신호!**

**6. 히스토그램 반전:**
- Hist 감소 (초록 작아짐!) → 음수 (빨강 커짐!)
- **=> 하락 시작!**

**7. Hist 지속 확대 (빨강 커짐!):**
- 하락 힘 지속 증가!
- **=> SHORT 지속!**

**8. MACD 고점 형성:**
- 상승 중 MACD 선이 고점 만들고 하락!
- **=> 정점! 반전!**

## 🌟 OBV 5가지 신호:

### **1. OBV 지속 상승:**
- 매크로 = **세력 매집 지속!**
- 조정 있어도 저점 갱신 X = 지지!
- **=> LONG 방향 유효!**

### **2. OBV 지속 하락:**
- 매크로 = **세력 분산 지속!**
- 반등 있어도 고점 갱신 X = 저항!
- **=> SHORT 방향 유효!**

### **3. OBV 다이버전스 (핵심!):**
- **가격 상승 + OBV 하락** = **세력 이탈 = 정점!** → SHORT!
- **가격 하락 + OBV 상승** = **세력 매집 = 저점!** → LONG!

### **4. OBV 급상승:**
- 세력 강력 매집!
- **=> 강력 LONG!**

### **5. OBV 급하락:**
- 세력 강력 분산!
- **=> 강력 SHORT!**

## 🎯 MACD + OBV 결합 매트릭스 (완벽!):

- 단기 = 반등!
- **=> 반등 완료 시 SHORT!**

### **E. 진입 금지 (혼란!)**
- **OBV LONG** + **MACD 강력 SHORT** = 혼란!
- **OBV SHORT** + **MACD 강력 LONG** = 혼란!
- **=> 스킵!**

### **F. 정점 감지 (다이버전스!) ⭐⭐⭐**

### **G. 저점 감지 (다이버전스!) ⭐⭐⭐**
