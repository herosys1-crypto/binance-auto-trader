# 2026-09-02 볼밴 진입 규칙 전면 교체 (Fix 276~280)

## 🌟 사장님 지시가 네 번에 걸쳐 도착했고, **마지막 문장이 전부를 지배했다**

1. "롱은 볼밴 하단 -10% 전후 / 숏은 최상단 +10% 전후면 무조건 진입"
2. "볼밴 상단을 돌파하면 우리로직이 고점이라 판단되면 진입"
3. "볼밴 하단 3-5번 지속 / 최상단 2-4번 지속되면 진입"
4. 🌟 **"꼭 3-5번 2-4번 -10% +10% 고정은 아니야. 이렇게 급락과 급등하면
   우리 시스템 로직이 **최고점 최저점이라 판단되면** 진입하고
   정말 그렇게 되면 **무조건** 포지션 진입하는거야"**

→ 봉수·심도는 **후보 감지**일 뿐, 진입을 정하는 건 **「극값에서 꺾임」**이다.
   네 지시가 규칙 **하나**로 합쳐진다: 밖으로 나감 → 극값 기록 → 꺾임 → 무조건 진입.
   **「무조건」은 「조건 없이」가 아니라 「판단되면 망설이지 말고」였다.**

## 🏆 최대 발견 — 「꺾임」 판정 하나가 건당 2.7배

    SHORT 상단 밖 4봉  꺾임 있음  174건 승률 **77.0%** 건당 **+1.800**

- **되돌림을 더 기다리면 나빠진다**(=늦는다): 0% > 0.3% > 0.6% > 1.0%(음수)
- 🚨 **SHORT 에 24h 급등 조건을 더하면 나빠진다**(+276 → −44) = 사장님 「무조건」이 맞다
- LONG 은 과적합 통과 조합이 「밖 2봉 + 반등 0.6%」 **하나뿐**(72건 +17.87, 건당 +0.248)

  그래도 「큰 하락」 안전망으로 OR 경로로 남겼다.
