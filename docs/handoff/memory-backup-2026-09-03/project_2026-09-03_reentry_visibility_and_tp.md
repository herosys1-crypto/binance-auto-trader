# 2026-09-03 세션 (Fix 299~301)

## 🚨 가장 큰 것 — 「99% 청산하고 남겨두기」는 **의도와 정반대**다

사장님 요구: "첫진입·두번째 진입에서 실패하면 지금은 모두 청산인데
**99% 청산하고** 다음 포지션을 진입 … 가능하면 99% 손절하고 남겨두는걸 원해"

**두 관문이 각각 단독으로 이걸 무효로 만든다** (`realtime_reentry_worker`):

1. 후보를 `status ∈ TERMINAL_STATUSES` (= **청산 완료**) 에서만 고른다
2. 그 다음 `if symbol in active_syms: continue` 로 **활성 심볼을 건너뛴다**

1% 를 남기면 상태가 `STAGE*_OPEN` 으로 살아 있어 **두 관문에 다 걸린다**
→ 그 심볼은 재진입 후보에서 **영구 제외**. 재진입이 아예 안 된다.

추가로 거래소 제약: **MIN_NOTIONAL = 5.00 USDT** (892심볼 최빈값, 최대 50).
1차 진입 10 × 레버 2 = 명목 20, 그 1% 는 **0.20 USDT** → reduceOnly 거부 =
영원히 못 파는 **dust orphan**. 사장님이 지목하신 「첫 진입」이 정확히 불가능 구간.
(2차 300 / 3차 600 부터는 6.00 / 12.00 이라 기술적으로는 가능하다.)

🔁 **「남겨두면 계속 감시된다」고 생각하기 전에, 감시자가 어떤 상태를 훑는지 먼저 볼 것.**
   여기서는 감시자가 **죽은 것만** 훑고 산 것은 건너뛴다 — 정확히 반대였다.

### 측정은 남겨 둔다 (OBV 자동 쪽에 쓸 수 있음)

→ 이건 **기본전략에는 쓰지 않는다**(사장님 설계). OBV 자동/볼밴 쪽 개선 후보로만 남긴다.
