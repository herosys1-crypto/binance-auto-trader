## 🌟 OBV 절대 우선 사상 (사장님 verbatim!):

### **핵심 원리:**
1. **OBV = 세력 활동 지표!** ⭐
2. **급등 확인** = OBV + 다른 지표 조합!
3. **조정 후 재상승** = **OBV 하나로 판단 가능!** ⭐⭐
4. **RSI vs OBV**: RSI = 결과 / **OBV = 원인!**
5. **조정 vs 급등락**: **OBV로 판단!** ⭐

### **적용 원칙:**

**OBV 상승 = 세력 매집!**
- 조정 중이라도 = OBV 상승 = **재상승 예정!**
- LONG 기회!

**OBV 하락 = 세력 분산!**
- 상승 중이라도 = OBV 하락 = **하락 예정!**
- SHORT 기회!

**OBV 다이버전스 = 핵심 반전 신호!**
- 가격 상승 + OBV 하락 = 세력 이탈 = **정점!** → SHORT
- 가격 하락 + OBV 상승 = 세력 매집 = **저점!** → LONG
