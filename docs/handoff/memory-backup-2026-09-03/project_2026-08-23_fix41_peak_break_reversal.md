## 🚨 필수 조건 (사장님 verbatim!):

**진입 전 = 확실한 하락 신호 확인 필수!**

### **차트 조건:**
- **위꼬리 음봉 (강한 매도!)**
- **연속 음봉 (2봉+ 하락!)**
- **BB 상단 이탈!**
- **거래량 폭발 (매도 우세!)**

### **보조지표 조건 (모두 AND!):**
- **RSI 6 = 하락 반전!** (전 봉 대비 -5% 이상!)
- **MACD Hist = 감소!** (양수 → 감소 or 음수!)
- **CCI 9 = 하락!** (전 봉 대비!)
- **OBV = 감소!** (매도세!)
- **볼륨 = 매도 우세!**

### **AND 조건 = 모두 통과 필수!**
- **하나라도 실패 = 진입 X!**
- **가짜 반전 = 절대 진입 X!**
- **확실한 하락 신호 = 100%!**

## 📊 진입 로직 (단계별!):

### **Phase 1: 최고가 A 감지!**
- 활성 SHORT = 진입 이후 15m 최고가 추적!
- Redis: `stage_peak_A:{strategy_id}:{stage}` = 최고가 A

### **Phase 2: 저점 감지!**
- 최고가 A에서 밀림!
- 저점 형성!
- Redis: `stage_low:{strategy_id}:{stage}` = 저점

### **Phase 3: 재상승 + 전고점 돌파!**
- 저점에서 상승!
- 최고가 A 돌파 감지!
- 신 최고가 B (> A!)
- Redis: `stage_peak_B:{strategy_id}:{stage}` = 최고가 B

### **Phase 4: 대기 모니터링!**
- 최고가 B 지속 갱신!
- 신 최고 D 형성!

### **Phase 5: 최고가 D에서 반전!**
- D 형성 후 = 하락 시작!
- **N% 하락 감지 = 진입 트리거!** (사장님 결정!)

### **Phase 6: 마틴게일 진입!**
- **2단계 = 600 USDT!**
- **3단계 = 1800 USDT!** (전고점 D 돌파 후 반전!)
- **4단계+ = 계속!** (사장님이 활성 결정!)
