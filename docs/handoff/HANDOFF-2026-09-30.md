- **하루 최대는 KST 기준** (하루 시작 = 15:00 UTC). 카운트는 `stage>=1` 인 건만.
- 배포 판정은 **프로세스 시작 시각 vs 파일 수정 시각**. `git log` 만 보고 「배포됨」이라 하지 말 것.
- CRLF 파일 다수 — 패치 스크립트는 줄끝 보존(`io.open(..., newline="")`).
- 작업 폴더에 0바이트 잡파일이 생긴다(훅의 `>`). 커밋 전 `git status --porcelain` 확인 후 **이름 지정 add**.
