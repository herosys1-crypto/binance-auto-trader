📋 사장님 요구 (2026-08-11)

"매일 학습하면서 급등과 급락이 예상되고 급락후 추가 지속적인 하락일경우 새전략을 만들어 분석한 전략으로 만들어줘 그것을 보고 자동또는 수동으로 매매를 할수 있게 해주고 기본은 수동으로 내가 실행할수 있게 해주고 차후에 자동으로도 할수 있게 선택옵션을 넣어서만들어주고 바로 사용하지 않은 전략은 유지 삭제 관리 가능하게 만들어진 시간도 표기해서 해줘"

🤖 5개 에이전트 상세

1. pump_dump_predictor (매일 06:30 UTC!)

미션: 급등/급락 예상 심볼 분석!

  • Market Flow 팀 학습 결과 참조!
  • Timezone Pattern 팀 통계 참조!
  • 4H OBV/RSI/BB 지표 분석!
  • 과거 유사 패턴 매칭!
  • 결과: 상위 20 예상 심볼 (pump/dump!)

2. descent_pattern_detector

미션: 급락 후 지속 하락 감지!

  • 최근 3~7일 = 급락 심볼!
  • OBV = 매도세 유지?
  • RSI = 30 이하 지속?
  • BB 하단 하방 이탈?
  • 결과: 지속 하락 예상 심볼!

3. strategy_suggestion_generator ⭐ 핵심!

미션: 신 전략 draft 자동 생성!

  • 예측 심볼 = 각각 전략 draft!
  • side, 자본, 트리거, TP/SL 자동 세팅!
  • 사장님 신 default 적용 (2x, TP 10/15/20/25, 강제 SL -15% 등!)
  • confidence_score 계산 (0~1.0)!
  • DB `strategy_suggestions` 저장!

4. suggestion_manager

미션: 유지/삭제 관리!

  • 사장님 = 「❌ 삭제」 클릭 = 즉시 제거!
  • 24h 미실행 = 자동 삭제 (선택!)
  • 실행 완료 = archived 마킹!

5. auto_manual_executor

미션: 자동 or 수동 실행!

  • 기본 = 수동! (사장님 「▶」 클릭!)
  • 사장님 옵션 = 「⚙ 자동 옵션」!
  • 자동 시 = 안전장치 필수 (검증!)
⚠️ 자동 실행 = 안전장치 필수!
  • confidence_score 임계 (0.85 이상만!)
  • 일일 자동 실행 한도!
  • 중복 심볼 방지!
  • 사장님 잔고 여유 확인!

🗃 DB 스키마 (alembic 0027!)

CREATE TABLE strategy_suggestions (
    id BIGSERIAL PRIMARY KEY,
    symbol VARCHAR(30) NOT NULL,
    side VARCHAR(10) NOT NULL,          -- LONG/SHORT
    suggestion_type VARCHAR(30),         -- pump_expected/dump_continuation/etc
    strategy_config JSONB NOT NULL,      -- 자본, 트리거, TP/SL 등!
    confidence_score DECIMAL(4, 3),      -- 0.000~1.000
    reason TEXT,                         -- 분석 이유!
    status VARCHAR(20) DEFAULT 'PENDING', -- PENDING/EXECUTED/DISMISSED/EXPIRED
    execution_mode VARCHAR(10) DEFAULT 'MANUAL', -- MANUAL/AUTO
    executed_at TIMESTAMPTZ,
    executed_strategy_id BIGINT,         -- 실 실행 후 = strategies.id!
    dismissed_at TIMESTAMPTZ,
    dismissed_reason TEXT,
    created_at TIMESTAMPTZ DEFAULT now(),
    updated_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_suggestions_status ON strategy_suggestions (status);
CREATE INDEX idx_suggestions_created ON strategy_suggestions (created_at DESC);

👑 사장님 매매 시나리오

시나리오 1: 수동 매매 (기본!)

  1. 대시보드 = 「🎯 전략 제안 [3건]」 확인!

  4. 「▶ 지금 실행」 클릭 = 신 전략 즉시!
  5. 포지션 진입!

시나리오 2: 자동 매매 (사장님 옵션!)

  1. 세팅 = 「🤖 자동 실행 ON」 저장!
  2. 매일 06:30 = 신 제안 생성!
  3. Confidence > 0.85 = 자동 실행!
  4. Telegram: "🤖 자동 진입! BTCUSDT SHORT"
  5. 사장님 확인만!

시나리오 3: 관리 (유지/삭제!)

  1. 제안 = 6시간 지남 (미실행!)
  2. 사장님 = 상황 변화로 = 「❌ 삭제」!
