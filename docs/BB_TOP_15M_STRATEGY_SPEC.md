## 🎛 로직 (구현 = `backend/app/services/bb_top_analyzer.py`)

### 다이버전스 판정

```
직전 극점 ref = 최근 20봉 중 최고가(천장) / 최저가(바닥) 지점

가격 신고가?  high[now] > high[ref]        ← 이게 먼저 성립해야 함
  AND RSI[now]  < RSI[ref]   → RSI 다이버전스
  AND MACD[now] < MACD[ref]  → MACD 다이버전스   (히스토그램 기준)
  AND OBV[now]  < OBV[ref]   → OBV 다이버전스
```
LONG(바닥)은 부호를 뒤집은 대칭 구조입니다 (헌법 5번).

## 🎯 볼밴 중단 — 목표이지 지지선이 아닙니다

천장 15,470건을 추적한 결과:

| 항목 | 실측 |
|---|---|
| 8시간 내 BB중단 **도달률** | **99.7%** |
| 도달까지 걸린 시간 | 중앙값 **2봉(30분)** / 평균 3.9봉 |
| 천장 → BB중단 하락폭 | 중앙값 **−1.84%** / 평균 −2.65% |

> **천장을 잡으면 BB 중단까지는 거의 확실히 갑니다.** → **TP1 = BB 중단**

### ⚠️ 그런데 중단에 닿은 뒤가 문제입니다

| BB중단 도달 후 2시간 | 비율 |
|---|---|
| **이탈 (−1%↓)** | **47.2%** |
| 반등 (+1%↑) | 18.3% |
| 양방향 흔들림 | 23.5% |
| 무반응 | 11.0% |

> **이탈이 반등의 2.6배입니다. BB 중단은 지지선이 아닙니다.**
> 이건 v131(「급등 후 BB중단 = 매수 기회」)의 가정과 **반대되는 실측 결과**입니다.
> → SHORT 진입 시 **BB 중단에서 전량 청산하지 말고 절반만**, 나머지는 BB 하단까지.
> → BB 중단 반등을 노린 LONG 되돌림 매수는 **성공률 18%** 임을 알고 하셔야 합니다.

상위 추세별 반등률도 16~20%로 큰 차이가 없어, **1H/4H로 반등을 예측할 수 없습니다.**

## ⚠️ 한계 (반드시 감안)

1. **천장(SHORT) 쪽만 실측 검증**했습니다. 바닥(LONG)은 대칭 구조로 구현했지만 **미검증**입니다.
2. **표본 기간 약 25일** (캐시된 15m 캔들 범위). 단일 시장 국면일 수 있습니다.
3. **적중률 37%는 「천장일 확률」**이지 수익률이 아닙니다. 나머지 63%는 천장이 아니었습니다.
4. 천장 라벨 정의(앞뒤 8봉 / −1.5%)를 바꾸면 수치가 달라집니다. 다른 정의로도 검증이 필요합니다.
5. **수수료·슬리피지 미반영**입니다.
6. 자동 주문 X — 사장님 판단 보조 + 학습 수집 전용입니다.
