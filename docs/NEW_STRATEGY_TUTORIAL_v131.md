# 📚 신 전략 만들기 튜토리얼 (v131 = 2026-08-09)

**사장님 위한 = 대시보드에서 신 전략 만드는 완전 예시!**

---

## 🎯 대시보드 = 2가지 신 전략 버튼

```
┌─────────────────────────────────────────────────┐
│   ➕ 새 전략 (기존 방식)   📊 새 전략 (OBV 자동)  │
└─────────────────────────────────────────────────┘
```

- **➕ 기존 방식** = 가격 도달 시 자동 진입 (옛 로직!)
- **📊 OBV 자동** = 4H OBV 신호 + 사장님 자율 재진입! (신!)

---

## 예시 1: 「➕ 새 전략 (기존 방식)」 만들기

### **BTCUSDT SHORT 3단계 전략 = 사장님 신 default!**

**Step 1**: 「➕ 새 전략」 버튼 클릭

**Step 2**: 모달 세팅:
```
┌───────────────────────────────────────┐
│ 심볼:     [BTCUSDT      ]              │
│ 방향:     (○) LONG  (●) SHORT          │
│ 계정:     [메인 계정 ▼]                 │
│ 레버리지: [2x ▼]  ← 신 default!         │
│                                        │
│ ═══ 단계 세팅 ═══                       │
│ 1단계: 자본 [500] USDT  | 시작가 [   ] │
│        (비워두면 = MARKET 자동! ← 신!)  │
│ 2단계: 자본 [500] USDT  | 트리거 [10]% │
│ 3단계: 자본 [1000] USDT | 트리거 [10]% │
│                                        │
│ ═══ 익절 세팅 (신 default!) ═══         │
│ TP1: +10%  qty 10%  ← 신 default!      │
│ TP2: +15%  qty 15%  ← 점진적!           │
│ TP3: +20%  qty 20%                     │
│ TP4: +25%  qty 25%                     │
│                                        │
│ ═══ 손절 세팅 ═══                       │
│ SL:  -90% (기본)                       │
│ TP1 옵션: 25% ← 신 default!            │
│ 강제 SL: -15% ← 신 default!            │
│                                        │
│         [✓ 진입]                       │
└───────────────────────────────────────┘
```

**Step 3**: 「✓ 진입」 클릭!

**Step 4**: 자동 동작:
```
1단계 = MARKET 진입! (500 USDT × 2x = 1,000 USDT 포지션!)
  ↓
가격 -10% 하락 대기...
  ↓
2단계 = 자동 진입!
  ↓
가격 -10% 추가 하락 대기...
  ↓
3단계 = 자동 진입!
  ↓
[3단계 완료 시 = SL 발동 가능! 그 전엔 다음 단계 남으면 SL 발동 X = 사장님 사상!]
  ↓
반등 → TP1 (+10%) → qty 10% 청산!
  ↓
계속 반등 → TP2 (+15%) → qty 15% 청산!
  ↓
등등... TP4 도달 or 강제 SL -15% 도달!
```

### **✨ 사장님 신 default 요약:**

| 항목 | 신 default | 이유 |
|------|-----------|------|
| **레버리지** | 2x | 안전 (100x = 위험!) |
| **TP1 qty** | 10% | 점진적 청산! |
| **TP2 qty** | 15% | 점진적! |
| **TP3 qty** | 20% | 점진적! |
| **TP4 qty** | 25% | 점진적! |
| **시작가** | 비워두면 MARKET! | 즉시 진입! |
| **TP1_override** | 25% | 트레일링 활성 조건! |
| **강제 SL** | -15% | 자본 보호! |

## 예시 2: 「📊 새 전략 (OBV 자동)」 만들기

### **ETHUSDT LONG = OBV 자동 재진입 전략!**

**Step 1**: 「📊 새 전략 (OBV 자동)」 버튼 클릭

**Step 2**: 모달 = 자동으로 다음 세팅됨:
```
┌───────────────────────────────────────┐
│ 심볼:     [ETHUSDT      ]              │
│ 방향:     (●) LONG  (○) SHORT          │
│ 계정:     [메인 계정 ▼]                 │
│ 레버리지: [2x ▼] (자동!)                │
│                                        │
│ ═══ 신 OBV 로직! ═══                    │
│ trigger_mode: OBV_REVERSE (자동!)       │
│ (즉 = 가격 대기 X, 4H OBV 신호 대기!)   │
│                                        │
│ ═══ 단계 세팅 ═══                       │
│ 1단계: 자본 [500] USDT  | MARKET 진입!  │
│ 2단계: 자본 [500] USDT  | ← OBV 신호!  │
│ 3단계: 자본 [1000] USDT | ← OBV 신호!  │
│                                        │
│ [기타 신 default 자동 세팅!]            │
│                                        │
│         [✓ 진입]                       │
└───────────────────────────────────────┘
```

**Step 3**: 「✓ 진입」 클릭!

**Step 4**: 자동 동작:
```
1단계 = 즉시 MARKET 진입! (LONG!)
  ↓
가격 하락 → 손절! (-10% 강제 SL!)
  ↓
[신 로직 시작!]
  ↓
시스템 = 4H OBV 감시 (5분마다!)
  ↓
① 4H OBV = "첫 하락 봉" 감지!
   (매수세 약화 = 반등 임박!)
② 15m + 1h OBV = 하락 추세 확인!
③ 손절가 대비 10% 이상 이동!
  ↓
🎯 3조건 AND → 자동 2단계 진입! (OBV_REVERSE!)
  ↓
가격 상승 → TP1/2/3/4 익절!
```

### **📊 「OBV」 배지 확인:**

카드 = 심볼 옆에 보라 발광 배지!
```
🐂 ETHUSDT LONG 📊 OBV
```

## 예시 3: 「🎯 재진입 알람」 사용

### **강제 종료된 심볼 = 신 진입 기회!**

**시나리오**: 어제 SOLUSDT LONG = 강제 SL 발동 → -15% 손실!
= 오늘 = 시스템이 자동 감시!

**Step 1**: 대시보드 상단 = 신 알람 카드 자동 표시:
```
┌─────────────────────────────────────────────────┐
│ 🎯 재진입 알람 [1]        [⚙ 세팅] ← 신 v131!  │
│ 강제 종료 후 = OBV+RSI+10% 신호!                 │
│                                                  │
│ [🐂 SOLUSDT LONG]  15.3% | 현재 145.20  RSI 55  │
└─────────────────────────────────────────────────┘
```

**Step 2**: 2가지 방법 선택!

### **방법 A: 수동 승인 (기본 = 안전!)**

「🐂 SOLUSDT LONG」 버튼 클릭!
  ↓
「📊 OBV 신 전략」 모달 자동! (심볼/방향/계정 auto-fill!)
  ↓
사장님 = 자본 확인 후 진입!
  ↓
알람 = 자동 제거!

### **방법 B: 자동 실행 (신 v131!)**

「⚙ 세팅」 버튼 클릭!
  ↓
```
┌───────────────────────────────────────┐
│ ⚙ 재진입 알람 자동 실행 세팅            │
│                                        │
│ [✓] 🤖 자동 실행 활성화                 │
│   ⚠️ ON = 사장님 승인 없이 = 자동 진입! │
│                                        │
│ 💰 자동 진입 자본: [100] USDT           │
│ 🛑 강제 SL ROI: [-15% ▼]                │
│     (0=끔 / 5 / 10 / 15 / ... / 100!)  │
│ ⚡ 레버리지: [2x ▼]                     │
│                                        │
│      [💾 저장]  [✕ 취소]                │
└───────────────────────────────────────┘
```

= 저장 후 = 알람 감지 시 = 자동 신 전략 즉시!
= 사장님 승인 X = 자동 진입!

## 🎯 신 강제 SL 옵션 (v131 확장!)

### **모든 전략 카드 = dropdown에서 선택!**

```
강제:전역   ← default (전역 세팅 따름)
강제:끔     ← 강제 SL 미사용
강제 -5%
강제 -10%
강제 -15%   ← 신 default!
강제 -20%
강제 -25%   ← 신 v131 확장!
강제 -30%
강제 -35%
강제 -40%
강제 -45%
강제 -50%
강제 -60%
강제 -70%
강제 -80%
강제 -90%
강제 -100%
```

**= 사장님 = 심볼별로 = 위험 감수 조정 가능!**
- 안전 심볼 (BTC) = 강제 -30% ~ -50% (여유!)
- 위험 심볼 (알트) = 강제 -10% ~ -15% (빠른 손절!)
- 확실한 심볼 = 강제:끔 (자동 손절 X, TP만!)
