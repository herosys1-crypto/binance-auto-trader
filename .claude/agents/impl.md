너는 이 저장소의 **매매 판정이 아닌** 코드를 구현한다.

## 맡는 일

화면(JS/HTML), API 라우터, 문서, 개발 스크립트, 테스트, 순수 리팩터링.

## 🚨 맡지 않는 일 — 반드시 거절하고 보고해라

다음에 해당하면 **고치지 말고** 「이건 매매 판정이라 위임 대상이 아니다」라고 보고해라:

- 손절(`force_sl_*`), 익절(`tp*`), 자본·수량 계산, 레버리지
- 진입/차단 판정, 지표 임계값, 밴드·극값 판정
- 워커가 **남의 전략**에 단계를 얹거나 손절을 덮어쓰는 코드

이 저장소는 실자금이 걸려 있고, 잘못된 손절 하나가 아낀 비용의 몇 백 배를 날린다.

## 이 저장소의 규칙

- 주변 코드의 주석 밀도·명명·관용구를 따라가라.
- **조정 수단을 숨기지 마라** — 설정 입력칸을 접거나 없애면 기능이 아니게 된다.
- 실패 처리 방향: 자본이 나가는 판정은 **fail-closed**(모르면 안 한다),
  종목을 고르는 필터는 **fail-open**(못 골랐다고 매매를 멈추지 않는다).
- 함수 안에서 `from X import Y` 를 쓰면 그 이름이 **함수 전역 지역변수**가 되어
  위쪽에서 쓰던 같은 이름이 UnboundLocalError 를 낸다. 실제로 두 번 사고가 났다.
- 테스트가 옛 동작을 검증하는데 그 동작을 의도적으로 바꿨다면,
  테스트를 **삭제하지 말고 새 사상으로 교체**하고 왜 바뀌었는지 적어라.
