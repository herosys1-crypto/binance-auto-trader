# 배치 실행기 — 실시간이 아니어도 되는 작업을 50%에

문서화 · 테스트 초안 · 죽은코드 탐지 · 주석-코드 감사 · 리팩터링 분석처럼
**결과를 나중에 봐도 되는** 일을 Message Batches API 로 돌린다.

## 왜 이게 따로 있나

Claude Code 의 서브에이전트(Agent/Workflow)는 **대화형 요청**으로 나간다.
배치로 보내는 스위치가 없다. 그래서 배치 할인을 받으려면 **일반 API 를 직접 부르는
별도 경로**가 필요하다 — 그게 이 도구다.

## 쓰는 법

```bash
# 0) 인증 (Claude Code 로그인과 별개)
export ANTHROPIC_API_KEY=sk-ant-...          # 또는  ant auth login

# 1) 무엇이 얼마나 드는지 먼저 본다 (API 호출 없음, 무료)
python -m tools.batch.run plan docstring_audit

# 2) 캐시가 이득인 작업이면 접두부를 먼저 데운다 (실시간 1건)
python -m tools.batch.run warm docstring_audit

# 3) 제출 (승인 프롬프트가 뜬다)
python -m tools.batch.run submit docstring_audit --limit 20

# 4) 진행 확인 → 회수
python -m tools.batch.run status
python -m tools.batch.run collect msgbatch_...
```

결과는 `docs/batch-out/<작업>/` 에 파일로 떨어진다.

## 작업 목록

| 작업 | 모델 | effort | 무엇을 하나 |
|---|---|---|---|
| `docstring_audit` | Sonnet 5 | medium | 주석이 주장하는 것 vs 코드가 실제로 하는 것 |
| `dead_code` | Haiku 4.5 | low | 미사용 상수·도달 불가 분기·중복 정의 |
| `tests` | Sonnet 5 | high | 순수 함수 pytest 초안 |
| `docs` | Haiku 4.5 | low | 모듈 참조 문서 |
| `refactor` | Sonnet 5 | high | 구조적 문제 (매매 규칙은 안 건드림) |

## 실측 비용 (이 저장소, 117개 파일 기준)

    docstring_audit   실시간 정가 $3.93  →  배치+캐시 $1.31   (67% 절감)
    tests             실시간 정가 $3.20  →  배치+캐시 $1.31   (59% 절감)
    dead_code         실시간 정가 $0.88  →  배치      $0.44   (50% 절감)

## 🚨 알아야 할 함정 세 가지

**① 캐시가 안 맞으면 오히려 비싸진다.**
1시간 TTL 캐시 **쓰기**는 1배가 아니라 **2배**다. 배치는 요청이 병렬 처리돼서
「첫 요청이 쓰고 나머지가 읽는다」가 보장되지 않는다. 전부 write 로 처리되면
캐싱을 안 한 것보다 비싸진다. → 그래서 `warm` 명령이 따로 있다.

**② 접두부가 짧으면 캐싱이 조용히 안 된다.**
최소 캐시 가능 접두부는 모델마다 512~4096 토큰이고, 그보다 짧으면
**에러 없이** 캐싱되지 않는다. 이 도구는 4,096 토큰을 넘길 때만 `cache_control` 을
붙인다 — 안 그러면 이득 0에 2배 쓰기 위험만 진다.
`plan` 이 「캐시 적용/미적용」을 알려준다.

**③ 캐싱이 항상 이득인 것도 아니다.**
공유 접두부가 작고 파일별 내용이 크면 캐싱은 노이즈다. 이 저장소에서
`dead_code` 는 접두부 295토큰 / 파일당 4,507토큰이라 캐싱을 아예 안 건다.
**진짜 절감은 배치 50%** 이고, 캐싱은 보조다.

`collect` 가 **실제** `cache_read_input_tokens` 와 청구 비용을 보고하므로
추정이 아니라 실측으로 확인할 수 있다.

## 🚨 안전 규칙

- 배치 작업은 전부 **읽고 보고만** 한다. 코드를 고치지 않는다.
- 생성물은 **초안**이다. 사람이 검토하기 전에 커밋하지 마라.
- **매매 로직·손절·자본 계산을 싼 모델에 맡기지 않는다.**
  잘못된 손절 하나가 배치로 아낀 돈의 몇 백 배를 날린다.

## 한계

- 배치는 대개 1시간 내, 최대 24시간. 급한 일에 쓰지 마라.
- 한 배치 최대 100,000건 / 256MB. 결과는 29일 보관.
- 요청끼리 **독립**이어야 한다. 앞 결과를 뒤 요청이 참조해야 하면 배치가 아니다.
- 가격표는 캐시된 값이다. 큰 배치 전에 `run models` 로 확인해라.
